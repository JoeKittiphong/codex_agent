# เริ่มใช้งานทันที

ใช้ไฟล์นี้เมื่ออยากให้ทีมเขียนนิยายพาจาก synopsis ไปจนถึงนิยายจริง

## ข้อมูลที่ควรส่งให้ทีม

- project slug สำหรับใช้เป็นชื่อโฟลเดอร์
- ชื่อเรื่องชั่วคราว
- แนวเรื่อง
- โทนเรื่อง
- กลุ่มเป้าหมาย
- เรื่องย่อหรือ synopsis
- จำนวนตอนเป้าหมาย หรือความยาวโดยรวม
- total word target ของทั้งเรื่อง
- สิ่งที่อยากให้มี
- สิ่งที่ห้ามมี
- มุมมองการเล่าเรื่อง ถ้ามี
- ระดับภาษา ถ้ามี
- ความต้องการด้านสำนวนบรรยาย เช่น อยากให้เน้นสัมผัสทั้งห้า หรือ prose แบบเข้าถึงอารมณ์ตัวละครมากเป็นพิเศษ

ถ้าต้องการสร้างโฟลเดอร์งานก่อนเริ่ม สามารถใช้:

```text
node tools/new-project.mjs [project-slug] [title]
```

## คำสั่งเริ่มงานแบบครบ workflow

```text
ใช้ทีมเขียนนิยายนี้ช่วยฉันพัฒนาจากเรื่องย่อไปเป็นนิยายจริง

ข้อมูลตั้งต้น:
- project slug: [เช่น glass-city-rain]
- ชื่อเรื่องชั่วคราว: [ใส่ชื่อ]
- แนวเรื่อง: [ใส่แนว]
- โทนเรื่อง: [ใส่โทน]
- กลุ่มเป้าหมาย: [ใส่กลุ่มเป้าหมาย]
- เรื่องย่อ: [ใส่ synopsis]
- จำนวนตอนเป้าหมาย: [ใส่จำนวนตอนหรือให้ระบบคำนวณ]
- total word target: [เช่น มากกว่า 100000 คำภาษาไทย]
- สิ่งที่อยากให้มี: [ใส่]
- สิ่งที่ห้ามมี: [ใส่]
- มุมมองการเล่าเรื่อง: [เช่น บุคคลที่สามจำกัดมุมมอง]
- ระดับภาษา: [เช่น อ่านง่าย กระชับ หรือวรรณศิลป์]
- สไตล์บรรยาย: [เช่น เน้นภาพ เสียง กลิ่น รส สัมผัส ให้ผู้อ่านรู้สึกเหมือนอยู่ในตัวละคร]

ให้ทำตามลำดับนี้:
1. ขยาย synopsis เป็นสามองก์
2. แตกเป็น 8 sequences
3. แตกเป็น 27 story points
4. สร้าง character bible
5. ทำ style sheet และ continuity tracker
6. วาง scene plan และจับฉากลงแต่ละตอนให้รองรับ total word target
7. เขียนนิยายจริงตอนละ 2500-3000 คำภาษาไทย หรือค่าตาม long-form plan โดยหนึ่งตอนต่อหนึ่งไฟล์
8. รีไรต์อย่างน้อย 1 รอบหลัง draft แรกเสร็จ
9. ใช้ format จาก references/output-templates.md และถ้าต้องสร้างไฟล์ให้วางไว้ใน manuscript/projects/[project-slug]/
```

## ถ้ายังไม่มี synopsis

```text
ฉันมีแค่ไอเดียตั้งต้น ช่วยขยายเป็น premise และ synopsis ก่อน แล้วค่อยทำ workflow นิยายเต็มต่อ
```

## คำสั่งเริ่มทีละขั้น

### ขยายเป็นสามองก์

```text
จาก synopsis นี้ ช่วยขยายเป็น Act 1, Act 2, Act 3 แบบพร้อมนำไปแตก 8 sequence ต่อ
```

### แตกเป็น 8 sequence

```text
จากโครงสามองก์นี้ ช่วยแตกเป็น 8 sequences โดยให้แต่ละ sequence มีหน้าที่ จุดขัดแย้ง mini-climax และจุดส่งต่อ
```

### แตกเป็น 27 story points

```text
จาก 8 sequences นี้ ช่วยแตกเป็น 27 story points ตาม references/story-points.md
```

### สร้างตัวละคร

```text
จาก 27 story points นี้ ช่วยสร้าง character bible ที่ผูกกับแต่ละจุดสำคัญของเรื่อง
```

### วาง scene plan

```text
จาก story points และตัวละครนี้ ช่วยแตกเป็นฉากว่าใคร ทำอะไร ที่ไหน อย่างไร และจัดฉากลงตอน
```

### เขียนตอนจริง

```text
จาก scene plan นี้ ช่วยเขียนตอนที่ 1 เป็นนิยายภาษาไทยจริงในสถานะ draft 1 ความยาว 2500-3000 คำหรือค่าตาม long-form plan พร้อมบทบรรยายและบทพูด โดยบรรยายให้เข้าถึงภาพ เสียง กลิ่น รส และสัมผัสผ่าน POV ของตัวละคร และเสนอชื่อไฟล์ตอน
```
