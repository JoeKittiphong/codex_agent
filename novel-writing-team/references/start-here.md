# เริ่มใช้งานทันที

ใช้ไฟล์นี้เมื่ออยากให้ทีมเขียนนิยายพาจาก synopsis ไปจนถึงนิยายจริง

ค่าเริ่มต้นของระบบคือ: ถ้าคุณส่งเรื่องย่อแล้วสั่งให้เริ่มทำ ระบบจะเดินทั้ง workflow ไปจนถึง `polished draft` ให้อัตโนมัติ โดยไม่ต้องสั่งซ้ำระหว่างทาง

## ข้อมูลที่ควรส่งให้ทีม

- project slug สำหรับใช้เป็นชื่อโฟลเดอร์
- ชื่อเรื่องชั่วคราว
- แนวเรื่อง
- โทนเรื่อง
- กลุ่มเป้าหมาย
- เรื่องย่อหรือ synopsis
- จำนวนตอนเป้าหมาย หรือความยาวโดยรวม
- total word target ของทั้งเรื่อง
- สิ่งที่อยากให้มี
- สิ่งที่ห้ามมี
- มุมมองการเล่าเรื่อง ถ้ามี
- ระดับภาษา ถ้ามี
- ความต้องการด้านสำนวนบรรยาย เช่น อยากให้เน้นสัมผัสทั้งห้า หรือ prose แบบเข้าถึงอารมณ์ตัวละครมากเป็นพิเศษ

ถ้าต้องการสร้างโฟลเดอร์งานก่อนเริ่ม สามารถใช้:

```text
node tools/new-project.mjs [project-slug] [title]
```

## คำสั่งเริ่มงานแบบครบ workflow

```text
ใช้ทีมเขียนนิยายนี้ช่วยฉันพัฒนาจากเรื่องย่อนี้ไปเป็นนิยายเต็มเรื่อง และเริ่มทำได้เลยจนจบ polished draft

ข้อมูลตั้งต้น:
- project slug: [เช่น glass-city-rain] (ถ้าไม่ใส่ ให้ระบบตั้งให้)
- ชื่อเรื่องชั่วคราว: [ใส่ชื่อ]
- แนวเรื่อง: [ใส่แนว]
- โทนเรื่อง: [ใส่โทน]
- กลุ่มเป้าหมาย: [ใส่กลุ่มเป้าหมาย]
- เรื่องย่อ: [ใส่ synopsis]
- จำนวนตอนเป้าหมาย: [ใส่จำนวนตอน หรือ ใส่ "ให้ระบบประเมิน" หรือระบุขนาด เช่น เรื่องสั้น/กลาง/ยาว]
- total word target: [เช่น 50000 คำ หรือ มากกว่า 100000 คำ หรือ ให้ระบบประเมิน]
- สิ่งที่อยากให้มี: [ใส่]
- สิ่งที่ห้ามมี: [ใส่]
- มุมมองการเล่าเรื่อง: [เช่น บุคคลที่สามจำกัดมุมมอง]
- ระดับภาษา: [เช่น อ่านง่าย กระชับ หรือวรรณศิลป์]
- สไตล์บรรยาย: [เช่น เน้นภาพ เสียง กลิ่น รส สัมผัส ให้ผู้อ่านรู้สึกเหมือนอยู่ในตัวละคร]

ให้ระบบ:
1. ล็อก assumption ที่จำเป็นเอง
2. สร้างไฟล์โปรเจกต์เอง
3. ทำ outline, scene plan, draft 1, rewrite, final audit และ editorial polish ให้ครบ
4. เขียน draft 1 ต่อเนื่องเป็น batch จนจบเรื่อง อัปเดต continuity และสถานะโปรเจกต์เอง
5. เดินต่ออัตโนมัติโดยไม่ต้องถามซ้ำทุกขั้น เว้นแต่มีปัญหาโครงสร้างสำคัญจริง
```

## ถ้ายังไม่มี synopsis

```text
ฉันมีแค่ไอเดียตั้งต้น ช่วยขยายเป็น premise และ synopsis ก่อน แล้วค่อยทำ workflow นิยายเต็มต่อ
```

## คำสั่งเริ่มทีละขั้น

### ขยายเป็นสามองก์

```text
จาก synopsis นี้ ช่วยขยายเป็น Act 1, Act 2, Act 3 แบบพร้อมนำไปแตก 8 sequence ต่อ
```

### แตกเป็น 8 sequence

```text
จากโครงสามองก์นี้ ช่วยแตกเป็น 8 sequences โดยให้แต่ละ sequence มีหน้าที่ จุดขัดแย้ง mini-climax และจุดส่งต่อ
```

### แตกเป็น 27 story points

```text
จาก 8 sequences นี้ ช่วยแตกเป็น 27 story points ตาม references/story-points.md
```

### สร้างตัวละคร

```text
จาก 27 story points นี้ ช่วยสร้าง character bible ที่ผูกกับแต่ละจุดสำคัญของเรื่อง โดยทำให้ตัวละครมีมิติ มีความขัดแย้งในตัวเอง และมี dialogue fingerprint ที่แยกเสียงกันได้
```

### วาง scene plan

```text
จาก story points และตัวละครนี้ ช่วยแตกเป็นฉากว่าใคร ทำอะไร ที่ไหน อย่างไร และจัดฉากลงตอน พร้อมระบุว่าฉากไหนเป็นการเปิดตัวครั้งแรกของคน สถานที่ หรือวัตถุสำคัญ และคนอ่านควรเห็นภาพอะไร
```

### เขียนตอนจริง

```text
จาก scene plan นี้ ช่วยเขียนตอนที่ 1 เป็นนิยายภาษาไทยจริงในสถานะ draft 1 ความยาว 2500-3000 คำหรือค่าตาม long-form plan พร้อมบทบรรยายและบทพูด โดยบรรยายให้เข้าถึงภาพ เสียง กลิ่น รส และสัมผัสผ่าน POV ของตัวละคร และถ้ามีการเปิดตัวครั้งแรกของคน สถานที่ หรือวัตถุสำคัญ ให้เขียนจนคนอ่านเห็นภาพจำได้ทันที พร้อมเสนอชื่อไฟล์ตอน
```

### คำสั่งสั้นแบบครั้งเดียวจบ

```text
นี่คือเรื่องย่อของฉัน ช่วยเริ่มทำเป็นนิยายเต็มเรื่องให้เลย และทำต่ออัตโนมัติจนเสร็จ polished draft
```

### ปิดงานทั้ง workflow แบบอัตโนมัติ

```text
เมื่อเริ่มทำแล้ว ให้เดินทั้ง workflow ตั้งแต่ outline ถึง polished draft โดยไม่ต้องถามซ้ำทุก batch เว้นแต่พบปัญหา continuity ระดับโครงสร้าง
```
