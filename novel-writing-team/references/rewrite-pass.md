# Rewrite Pass Guide

ใช้เอกสารนี้เมื่อ draft แรกของนิยายเขียนเสร็จแล้ว และต้องทำ rewrite อย่างน้อย 1 รอบ

## เป้าหมายของ rewrite pass
- ทำให้ภาษาแน่นขึ้น ลื่นขึ้น และมีภาพมากขึ้น
- เพิ่ม immersion ผ่านภาพ เสียง กลิ่น รส และสัมผัส
- เกลาจังหวะบทพูด บทบรรยาย และจุดลงอารมณ์
- ตัดประโยคซ้ำ ความคิดซ้ำ หรือคำอธิบายตรงเกินไป
- รักษาพล็อตเดิม แต่ทำให้การเล่าทรงพลังขึ้น

## สิ่งที่ควรตรวจใน rewrite

### 1. Language Tightening
- ตัดคำฟุ่มเฟือย
- เปลี่ยนประโยคอธิบายเป็นภาพหรือการกระทำเมื่อเหมาะสม
- ลดคำซ้ำและโครงประโยคซ้ำกันติดๆ

### 2. Sensory Enrichment
- เพิ่มรายละเอียดที่ทำให้ฉากเป็นกายภาพ
- ตรวจว่ารายละเอียดสัมผัสผูกกับ POV ของตัวละครจริง
- อย่าใส่ทุกสัมผัสแบบฝืน แต่ให้ทั้งตอนมีมิติสัมผัสครบพอ

### 3. Emotional Precision
- ให้ภาษากาย จังหวะเงียบ และรายละเอียดเล็กๆ ช่วยแบกอารมณ์
- ลดการบอกอารมณ์ตรงๆ ถ้าสามารถทำให้รู้สึกได้จากฉาก

### 4. Dialogue Polish
- ตรวจเสียงพูดของแต่ละตัวละครให้แยกกันชัด
- ตัดบทพูดที่อธิบายเกินธรรมชาติ
- ใส่จังหวะหายใจ การหยุด หรือ gesture เมื่อจำเป็น

### 5. Scene Momentum
- ทุกฉากควรจบด้วยการเปลี่ยนแปลง คำถามใหม่ หรือแรงค้าง
- ถ้าช่วงใดยืด ให้ย่อโดยคงอารมณ์หลักไว้

## รูปแบบการทำงานที่แนะนำ
1. เขียน draft แรกให้ครบทั้งตอนหรือครบทั้งเรื่อง
2. ทำ editorial pass เพื่อหาจุดอ่อนหลัก
3. ทำ rewrite pass อย่างน้อย 1 รอบ
4. อัปเดต continuity ถ้ามีการปรับรายละเอียดเล็กน้อย
5. ล็อกเป็น draft 2
6. ทำ final continuity + word-count audit
7. ทำ editorial polish pass แล้วจึงล็อกเป็น polished draft

## Continuous Rewrite Batches
- ถ้าผู้ใช้สั่งรีไรต์ทั้งเรื่อง ให้ทำงานเป็น batch ต่อเนื่อง เช่น ตอน 1-4, 5-8, 9-12
- แต่ละ batch ควรเป็นตอนที่ต่อกัน เพื่อคุมเสียงภาษา อารมณ์ และ continuity ได้ง่าย
- หลังจบแต่ละ batch ให้บันทึกใน `rewrite-log.md` ว่ารีไรต์ถึงตอนใดแล้ว
- ให้อัปเดต `README.md` ของโปรเจกต์และ `manuscript/projects/index.md` ทุกครั้ง
- ทำต่อเนื่องจนกว่าจะครบทั้งเรื่อง เว้นแต่ผู้ใช้สั่งหยุดหรือเปลี่ยนแผน
- เมื่อรีไรต์ครบทั้งเรื่องแล้ว ให้ส่งต่องานไป `references/final-audit.md` โดยอัตโนมัติ ถ้าผู้ใช้มีเจตนาให้ปิด workflow จนจบ
- ถ้า final audit ผ่านหรือมีเพียง issue ระดับย่อย ให้ส่งต่อเข้า `references/editorial-polish.md` โดยไม่ต้องถามซ้ำ
