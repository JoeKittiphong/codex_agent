# Continuity Tracker

ใช้เอกสารนี้เพื่อติดตามข้อมูลสำคัญข้ามตอน และลดปัญหาข้อมูลหลุดหรือขัดกันเอง

## สิ่งที่ควรติดตาม
- เส้นเวลา
- สถานะตัวละคร
- ความสัมพันธ์
- ความลับที่เปิดเผยแล้ว/ยังไม่เปิด
- วัตถุสำคัญ
- บาดแผลและสภาพร่างกาย
- สถานะสถานที่หรือโลก
- คำสัญญา คำโกหก และข้อมูลที่ต้องจ่ายคืนภายหลัง

## รูปแบบที่แนะนำ

```text
Continuity Tracker

Timeline
- วัน/เวลา:
- เกิดอะไรขึ้น:
- อยู่ในตอน:

Character State
- ตัวละคร:
- สถานะล่าสุด:
- บาดแผล/ร่องรอย:
- อารมณ์คงค้าง:
- ความลับที่รู้:
- สิ่งที่ยังไม่รู้:
- คำสัญญาหรือภาระที่แบกอยู่:

Relationship State
- คู่ความสัมพันธ์:
- สถานะปัจจุบัน:
- เปลี่ยนจากอะไร:
- ต้องระวังอะไรในตอนถัดไป:

Object / Clue Tracker
- วัตถุหรือเบาะแส:
- ปรากฏครั้งแรก:
- ตอนนี้อยู่ที่ใคร:
- หน้าที่ต่อพล็อต:
- ต้องจ่ายคืนเมื่อไร:

Open Loops
- คำถามที่ยังไม่คลี่คลาย:
- เปิดไว้ตั้งแต่ตอน:
- ควรกลับมาจ่ายคืนประมาณตอนไหน:
```

## หลักการใช้งาน
- อัปเดตหลังเขียนทุกตอน
- ตรวจ continuity tracker ก่อนเริ่มตอนใหม่
- ถ้ามี retcon ให้บันทึกเหตุผลไว้ชัด
