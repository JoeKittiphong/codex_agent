# Novel Sizing & Long-form Planning

ใช้เอกสารนี้เพื่อกำหนดขนาดนิยายและวางแผนจำนวนตอน ทั้งแบบที่ผู้ใช้ระบุเองและแบบที่ agent ประเมินให้

## ขนาดนิยาย 3 ระดับ

| ระดับ | จำนวนตอน | Total Word Target | Words/Episode | เมื่อไรควรใช้ |
|-------|----------|-------------------|---------------|--------------|
| เรื่องสั้น | 5-10 ตอน | 15,000-30,000 คำ | 2,500-3,500 คำ | เรื่องพล็อตเดี่ยว ตัวละครหลัก 1-2 คน ไม่มี subplot ซับซ้อน |
| เรื่องขนาดกลาง | 12-24 ตอน | 35,000-70,000 คำ | 2,500-3,500 คำ | มี subplot 1-2 เส้น ตัวละครหลัก 2-4 คน มี turning point ชัด 2-3 จุด |
| เรื่องยาว | 25-40 ตอน | 75,000-120,000+ คำ | 2,500-4,000 คำ | มี subplot หลายเส้น ตัวละครหลัก 3+ คน world-building ซับซ้อน หรือผู้ใช้ระบุว่าต้องการนิยายเต็ม |

## วิธีเลือกขนาด

1. **ผู้ใช้ระบุมาเอง** → ใช้ค่าที่ผู้ใช้ให้เสมอ ไม่ว่าจะเป็นจำนวนตอน หรือ total word target
2. **ผู้ใช้ไม่ได้ระบุ** → ประเมินจาก synopsis ดังนี้:
   - นับจำนวนตัวละครหลัก, subplot, และ turning point ที่ปรากฏใน synopsis
   - ถ้า synopsis สั้นและเรียบง่าย (1 พล็อต, 1-2 ตัวละคร) → เรื่องสั้น
   - ถ้ามีความซับซ้อนปานกลาง → เรื่องขนาดกลาง
   - ถ้ามี world-building, หลาย subplot, หรือผู้ใช้ใช้คำว่า "นิยายเต็ม" / "complete novel" → เรื่องยาว
3. **ล็อกขนาดที่เลือกใน assumption** พร้อมเหตุผลสั้นๆ ว่าทำไมเลือกขนาดนี้

## ผู้ใช้สามารถกำหนดได้อย่างยืดหยุ่น

ผู้ใช้สามารถระบุขนาดนิยายได้หลายวิธี:
- `จำนวนตอนเป้าหมาย: 15` → agent ใช้ค่านี้ตรงๆ
- `total word target: 50000` → agent คำนวณจำนวนตอนจาก target ÷ words/ep
- `อยากได้เรื่องสั้นๆ` / `อยากได้เรื่องยาวเต็ม` → agent เลือกระดับที่ตรงกัน
- ไม่ระบุเลย → agent ประเมินจาก synopsis ตามเกณฑ์ด้านบน

## หลักการวางโครงยาว (สำหรับเรื่องขนาดกลางขึ้นไป)

1. ล็อก synopsis หลัก
2. ขยาย 3 acts และ 8 sequences
3. แตก 27 points ให้ชัด
4. ขยายแต่ละ point เป็นหลาย scene arc เมื่อเรื่องต้องยาวระดับนวนิยายเต็ม
5. ทำ episode map โดยคุมว่าทุกตอนมี opening, escalation, payoff, ending hook
6. ตั้ง total word target ตั้งแต่ต้นและตรวจสะสมทุก 5 ตอน

## หลักการวางโครงสั้น (สำหรับเรื่องสั้น 5-10 ตอน)

1. ล็อก synopsis หลัก
2. ขยาย 3 acts (อาจย่อเป็น mini-act)
3. แตก story points ตามจำนวนตอนจริง (ไม่จำเป็นต้องครบ 27 points — ใช้ points ที่สำคัญต่อเรื่อง)
4. ทำ episode map ตรงๆ โดยไม่ต้องผ่าน 8 sequences ถ้าไม่จำเป็น
5. ตั้ง total word target ตั้งแต่ต้น

## การคุมความยาว

- บันทึกใน series bible:
  - total word target
  - target words per episode
  - expected episode count
- อัปเดตยอดคำจริงใน episode map หรือ project README เป็นระยะ
- ถ้าต้องการตอนยาวขึ้น เช่น 3000-4000 คำ อาจลดจำนวนตอนลงได้ แต่ต้องคุมจังหวะไม่ให้ยืด

## การขยายเรื่องอย่างมีคุณภาพ (สำหรับเรื่องยาว)

อย่ายืดเรื่องด้วยฉากซ้ำหน้าที่ ให้ขยายด้วย:
- ภารกิจย่อยที่มีผลต่อ arc
- ฉากความสัมพันธ์ที่เปลี่ยนสถานะจริง
- ปมรองที่ผูกกับธีมหรือโลกของเรื่อง
- aftermath ของเหตุการณ์ใหญ่
- turning decisions ที่มีราคาต้องจ่าย

## สิ่งที่ไม่ควรทำ

- ยืดด้วยบทบรรยายสวยแต่ไม่ขยับเรื่อง
- เพิ่มตัวละครที่ไม่มีหน้าที่ต่อพล็อต
- ใส่ฉากซ้ำอารมณ์เดิมโดยไม่เปลี่ยนความสัมพันธ์หรือข้อมูล
- บังคับเรื่องสั้นให้ยาว 30+ ตอน เมื่อเนื้อเรื่องไม่รองรับ
