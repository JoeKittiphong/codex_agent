# Character Design Guide

ใช้เอกสารนี้เมื่อสร้าง `character bible` เพื่อให้ตัวละครมีมิติ จำได้ง่าย และมีเสียงพูดเฉพาะตัว

## เป้าหมาย
- ตัวละครต้องไม่ใช่แค่ "บทบาทในพล็อต" แต่เป็นคนที่มีแรงขับ ความขัดแย้ง และวิธีตอบสนองต่อแรงกดดันต่างกัน
- ผู้อ่านควรพอเดาได้ว่าใครกำลังพูดอยู่ แม้ตัดชื่อหน้า dialogue tag ออกไป
- ตัวละครทุกตัวต้องส่งผลต่อ story points และถูก story points เปลี่ยนกลับด้วย

## หลักออกแบบตัวละครที่ต้องมี

### 1. หน้าที่ต่อเรื่อง
ตอบให้ได้ก่อนว่า ตัวละครนี้มีไว้ทำอะไร
- ขับพล็อต
- สร้างแรงต้าน
- เปิดมุมมองใหม่
- เป็นกระจกสะท้อน theme
- เป็น foil ให้ตัวเอก
- เป็นคนที่บังคับให้ตัวเอกเปลี่ยน

ถ้าตัวละครไม่มีหน้าที่ชัด ให้ตัด รวม หรือเปลี่ยนบทบาท

### 2. แกนตัวตน + ความขัดแย้งในตัวเอง
ตัวละครที่มีมิติควรมี "ความจริง 2 ด้าน" ที่ชนกันอยู่ เช่น
- อยากถูกรัก แต่ไม่เชื่อใจใคร
- เก่งควบคุมสถานการณ์ แต่ควบคุมอารมณ์ตัวเองไม่ได้
- ดูอ่อนโยน แต่ตัดสินใจโหดเมื่อถูกบีบมุม

ให้ระบุอย่างน้อย:
- สิ่งที่ตัวละครแสดงออกให้โลกเห็น
- สิ่งที่ซ่อนอยู่จริง
- จุดขัดแย้งหลักในตัวเอง

### 3. Desire / Need / Fear / Misbelief
ตัวละครควรมีอย่างน้อย 4 ชั้นนี้
- เป้าหมายภายนอก: สิ่งที่อยากได้ในเชิงพล็อต
- ความต้องการภายใน: สิ่งที่ต้องเรียนรู้หรือยอมรับ
- ความกลัวหลัก: สิ่งที่พยายามหนี
- ความเชื่อผิดพลาด: ประโยคที่เขาเชื่อเกี่ยวกับโลกหรือเกี่ยวกับตัวเอง เช่น "ถ้าอ่อนแอเมื่อไรจะถูกทิ้งทันที"

### 4. บาดแผล + กลไกป้องกันตัว
บาดแผลที่ดีไม่ใช่แค่ประวัติเศร้า แต่ต้องส่งผลต่อพฤติกรรมปัจจุบัน
- บาดแผลคืออะไร
- มันทำให้ตัวละครตีความโลกอย่างไร
- เวลาถูกกระตุ้น เขาป้องกันตัวแบบไหน
  - เงียบ
  - โกหก
  - ประชด
  - คุมทุกอย่าง
  - ยอมคนเกินไป
  - ใช้อารมณ์ขันบังหน้า

### 5. เส้นศีลธรรมและราคาที่ยอมจ่าย
กำหนดให้ชัดว่า
- อะไรคือเส้นที่เขาบอกว่าจะไม่ข้าม
- เมื่อไรเขาอาจยอมข้ามเส้นนั้น
- ราคาอะไรที่เขายอมจ่าย และราคาอะไรที่ยอมไม่ได้

ตรงนี้ทำให้การตัดสินใจมีเอกลักษณ์ ไม่ใช่ตอบสนองแบบทั่วๆ ไป

### 6. วิธีใช้อำนาจและอยู่ในความสัมพันธ์
ตัวละครแต่ละคนควรมีวิธีอยู่กับคนอื่นไม่เหมือนกัน เช่น
- คุมห้องด้วยความเงียบ
- ชนะด้วยข้อมูล
- เอาตัวรอดด้วยเสน่ห์
- ยอมถอยเพื่อเก็บหนี้บุญคุณไว้ทีหลัง
- พูดตรงจนคนอื่นถอยเอง

ให้ระบุด้วยว่าเขาเปลี่ยนโหมดอย่างไรเมื่ออยู่กับ
- คนที่เหนือกว่า
- คนที่อ่อนแอกว่า
- คนที่รัก
- คนที่ไม่ไว้ใจ

### 7. ภาษากายและพฤติกรรมติดตัว
เอกลักษณ์ไม่ควรอยู่แค่คำพูด
- เวลาคิดจะทำอะไรกับมือ สายตา หรือท่าทาง
- เวลากดดันจะเร็วขึ้นหรือช้าลง
- เวลาปิดบังความรู้สึกจะทำอะไร
- รายละเอียดทางกายที่สะท้อนสภาพใจ

ใช้เป็น "pattern" ไม่ใช่ gimmick ซ้ำจนเกินจริง

## Dialogue Fingerprint

ส่วนนี้สำคัญมาก ถ้าต้องการให้ "เห็นบทพูดก็รู้ว่าเป็นใคร"

### ต้องออกแบบอย่างน้อย 8 มิติ
1. **ระดับภาษา** — หยาบ/สุภาพ/ทางการ/กันเอง
2. **จังหวะประโยค** — สั้นห้วน, ยาวเป็นคลื่น, ชอบเว้น, ชอบถามกลับ
3. **คำที่ชอบใช้** — คำติดปาก คำเรียกคน คำเชื่อม
4. **คำที่ไม่ใช้** — เช่น บางคนไม่พูดคำว่าขอโทษตรงๆ บางคนไม่เรียกชื่อจริง
5. **ระดับความตรง** — พูดตรง, อ้อม, หลบ, พูดครึ่งเดียว
6. **วิธีใช้อารมณ์ขัน/ประชด** — มีไหม ใช้เพื่อแทง, กันตัวเอง, ลดความตึง, หรือไม่ใช้เลย
7. **รูปแบบเวลาถูกบีบคั้น** — เงียบลง, พูดเร็วขึ้น, หลุดคำหยาบ, ตัดคำฟุ่มเฟือยทิ้ง
8. **วิธีพูดความจริงยากๆ** — พูดตรง, เบี่ยงประเด็น, พูดเป็นงาน, พูดผ่านการกระทำแทน

### สิ่งที่ช่วยให้เสียงพูดจำได้
- คลังคำเปรียบเทียบเฉพาะตัว เช่น คนช่างจะเปรียบกับเครื่อง คนครัวจะเปรียบกับไฟหรือรส
- รูปแบบการเรียกอีกฝ่าย เช่น "คุณ" "แก" "พี่" "เธอ" หรือไม่เรียกชื่อเลย
- ระดับความชัดของข้อมูล บางคนตอบตรง บางคนตอบเฉพาะส่วนที่ปลอดภัย
- การใช้ silence เป็นคำตอบ
- วิธีโกหก: เรียบเกินไป, พูดเยอะเกินไป, เปลี่ยนเรื่อง, ถามกลับ

### ข้อควรระวัง
- อย่าพึ่งแต่คำติดปากคำเดียว เพราะจะกลายเป็นการ์ตูน
- อย่าให้ทุกคนฉลาดคมแบบเดียวกัน หรือประชดแบบเดียวกัน
- น้ำเสียงต้องออกมาจากโลกทัศน์ ไม่ใช่แค่เครื่องประดับ

## แบบทดสอบความแข็งแรงของตัวละคร

### Test 1: Name-stripped Dialogue Test
ลบชื่อหน้า dialogue tag ออก 5-8 บรรทัด
- ถ้าคนอ่านยังเดาได้ว่าใครพูดอย่างน้อย 70% แปลว่าเสียงเริ่มชัด
- ถ้าสลับชื่อกันแล้วไม่รู้สึกผิด แปลว่ายังแยกเสียงไม่พอ

### Test 2: Pressure Test
ถามว่าเมื่อถูกกดดัน ตัวละครจะ
- ปกป้องอะไรเป็นอย่างแรก
- โทษใครก่อน
- ยอมเสียอะไร
- ปิดบังอะไร

ถ้าตอบเหมือนตัวละครอื่นหลายตัว แปลว่ายังไม่เฉพาะพอ

### Test 3: Choice Test
เอาสถานการณ์เดียวกันให้ตัวละคร 3 คนเลือก
- ถ้าทุกคนเลือกคล้ายกันเกินไป ให้กลับไปเพิ่มเส้นศีลธรรม ความกลัว หรือวิธีใช้อำนาจ

## สิ่งที่ character bible ที่ดีควรบอกได้
สำหรับตัวละครหลักแต่ละตัว ควรตอบได้อย่างน้อยว่า
- เขาอยากอะไร
- เขาต้องเรียนรู้อะไร
- เขาโกหกตัวเองเรื่องอะไร
- เขาป้องกันตัวอย่างไร
- เขาทำให้ฉากเปลี่ยนพลังงานอย่างไรเมื่อเดินเข้ามา
- เขาคุยไม่เหมือนใครอย่างไร
- เขาจะพังอย่างไรเมื่อถูกกดดัน
- เขาจะเปลี่ยนอย่างไรเมื่อถึงปลายเรื่อง

## รูปแบบข้อมูลที่แนะนำใน Character Bible
- บทบาทต่อเรื่อง
- Archetype / หน้าที่ในพล็อต
- ภาพลักษณ์ภายนอก
- ภาพจำแรกตอนเปิดตัว
- ภาพลักษณ์ที่คนอื่นเข้าใจ
- ตัวตนจริงลึกลงไป
- แกนตัวตน / contradiction
- เป้าหมายภายนอก
- ความต้องการภายใน
- ความกลัวหลัก
- ความเชื่อผิดพลาด
- บาดแผล / ปม
- กลไกป้องกันตัว
- ความลับ
- จุดแข็ง / จุดอ่อน
- เส้นศีลธรรม
- จุดเปราะบาง / trigger
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง
- ความสัมพันธ์สำคัญ
- Story points ที่มีบทบาท
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง
- Dialogue fingerprint
- ตัวอย่างบทพูด 3 แบบ: ปกติ / กดดัน / เปราะบาง
- สิ่งที่ห้ามหลุดคาแรกเตอร์

## Anti-patterns ที่ควรหลีกเลี่ยง
- ให้ตัวละครมีแค่ backstory แต่ไม่มีพฤติกรรมปัจจุบัน
- ให้ทุกคนพูดเหมือนผู้เขียนคนเดียวกัน
- ใช้ trauma เป็นของตกแต่งแต่ไม่ส่งผลต่อ choice
- ให้ "quirk" แปลกๆ แต่ไม่โยงกับความขัดแย้งภายใน
- ให้ตัวละครดีหรือเลวแบบเส้นตรงจนไม่มีแรงเสียดทาน
- ใส่ตัวละครรองจำนวนมากแต่ไม่มีใครเปลี่ยนพลังของฉากจริง

## Checklist สั้นก่อนส่ง Character Bible
- มีความขัดแย้งในตัวเองอย่างน้อย 1 จุดหรือไม่
- มี misbelief หรือ blind spot ชัดหรือไม่
- เมื่อกดดันแล้วพฤติกรรมเปลี่ยนอย่างจำได้หรือไม่
- มีวิธีพูดเฉพาะตัวมากกว่าคำติดปากหรือไม่
- มีตัวอย่างบทพูด 3 แบบหรือไม่
- บทบาทต่อ story points ชัดหรือไม่
- มีสิ่งที่ห้ามหลุดคาแรกเตอร์ชัดหรือไม่
- ถ้าตัดชื่อออกจากบทพูด คนอ่านยังพอเดาได้หรือไม่
