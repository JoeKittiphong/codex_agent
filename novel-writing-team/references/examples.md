# ตัวอย่างการใช้งาน

## ตัวอย่าง Three-Act Expansion

```text
Act 1: เมืองที่ยังไม่รู้ว่ากำลังพัง
- หน้าที่ขององก์: เปิดโลก แนะนำตัวเอก และทำให้เขาจำใจต้องรับภารกิจ
- สถานะตัวเอกตอนต้น: ยังเชื่อว่าการเอาตัวรอดคนเดียวคือวิธีที่ดีที่สุด
- เหตุการณ์หลัก: พบเบาะแสเรื่องการหายตัวไปของน้องสาวและรู้ว่ารัฐปิดบังความจริง
- แรงกดดัน / คำถามหลัก: เขาจะยอมเสี่ยงเปิดโปงความจริงหรือไม่
- สถานะตัวเอกตอนปลายองก์: ตัดสินใจออกจากพื้นที่ปลอดภัยและเริ่มตามหาความจริง
- เดิมพัน: ถ้าพลาด เขาอาจเสียน้องสาวไปตลอดกาล
- จุดส่งต่อไป Act 2: ตัวเอกออกเดินทางพร้อมข้อมูลชิ้นแรก
```

## ตัวอย่าง 8 Sequence

```text
Sequence 4: สัญญาณว่าศัตรูรู้ทัน
- อยู่ใน Act: 2
- หน้าที่ของช่วง: เพิ่มอุปสรรคและพาเรื่องไปสู่ turning point
- จุดเริ่มต้น: ตัวเอกคิดว่าตนเริ่มควบคุมสถานการณ์ได้
- เป้าหมายของตัวเอกในช่วงนี้: แทรกซึมเข้าไปเอาหลักฐานจากคลังข้อมูล
- ความขัดแย้งหลัก: ผู้มีอำนาจวางกับดักและหนึ่งในพวกเดียวกันอาจทรยศ
- Mini-climax: หลักฐานถูกดึงออกมาได้ แต่ต้องแลกกับการเปิดเผยตำแหน่งของทีม
- จุดจบของช่วง: ฐานที่มั่นถูกบุก
- สิ่งที่ส่งต่อไป sequence ถัดไป: เรื่องเข้าสู่ turning point และ bad coming
```

## ตัวอย่าง Character Bible

```text
ตัวละคร: ภูริ
- บทบาทต่อเรื่อง: ตัวเอก
- Archetype / หน้าที่ในพล็อต: ผู้รอดชีวิตที่ต้องเรียนรู้การเชื่อใจคนอื่น
- อายุ / ภาพลักษณ์: 27 ปี ผอมสูง สีหน้าเหมือนคนอดนอนมานาน
- ภาพจำแรกตอนเปิดตัว: ผู้ชายผอมสูงในเสื้อสีหม่นที่ยืนเหมือนหาทางหนีไว้ก่อนทุกครั้ง แม้เพิ่งหยุดเดิน
- ภาพลักษณ์ที่คนอื่นเข้าใจ: เย็นชา พึ่งพายาก เหมือนคนไม่แคร์ใคร
- ตัวตนจริงลึกลงไป: ระวังทุกอย่างเพราะกลัวการสูญเสียซ้ำมากกว่ากลัวอันตรายเอง
- แกนตัวตน / ความขัดแย้งในตัวเอง: อยากปกป้องคนของตัวเอง แต่เชื่อว่าการผูกพันจะทำให้ตัวเองพาคนอื่นพัง
- เป้าหมายภายนอก: ตามหาน้องสาวและเปิดโปงโครงการลับ
- ความต้องการภายใน: ยอมรับว่าตัวเองไม่อาจแบกทุกอย่างคนเดียว
- ความกลัวหลัก: เป็นคนพาคนที่รักไปตายอีกครั้ง
- ความเชื่อผิดพลาด: ถ้าไม่เปิดใจและคุมทุกอย่างไว้เอง ความเสียหายจะน้อยกว่า
- บาดแผล / ปม: เคยปล่อยให้ครอบครัวแตกสลายเพราะเลือกเอาตัวรอด
- กลไกป้องกันตัว: ตัดบท พูดสั้น และทำตัวเหมือนไม่รู้สึก
- ความลับ: เขาเคยทำงานรับจ้างให้ฝ่ายรัฐโดยไม่รู้ผลกระทบเต็มรูปแบบ
- จุดอ่อน: ไม่ไว้ใจใครและตัดสินใจเร็วเกินไปเมื่อถูกกดดัน
- จุดแข็ง: อ่านสถานการณ์ไวและกล้าตัดสินใจ
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่ขายตำแหน่งของคนบริสุทธิ์แม้ต้องเอาตัวรอด
- จุดเปราะบาง / trigger: เด็กหรือคนในครอบครัวที่ถูกใช้เป็นเครื่องมือ
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: คุมสถานการณ์ด้วยข้อมูลและการตัดสินใจเร็ว มากกว่าการโน้มน้าวใจยาวๆ
- ภาษากายหรือพฤติกรรมติดตัว: ชอบกอดอก มองทางหนีไว้ก่อน และเลี่ยงสบตานานเมื่อเริ่มรู้สึกผิด
- ความสัมพันธ์สำคัญ: ปะทะกับเมษาแต่พึ่งพาเธอมากขึ้นเรื่อยๆ
- Story points ที่มีบทบาท: 1, 5, 7, 13, 18, 24, 26, 27
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: คนโดดเดี่ยว -> คนที่ยอมรับความช่วยเหลือ -> คนที่กล้ายืนหยัดเพื่อคนอื่น
- Dialogue Fingerprint:
  - ระดับภาษา: สุภาพแบบห่างๆ ไม่สนิทก็ไม่หยาบ
  - จังหวะประโยค: สั้น ตัดคำฟุ่มเฟือย ทิ้งน้ำหนักท้ายประโยค
  - คำที่ชอบใช้: "เอาที่จำเป็น" "พอ" "เดี๋ยวฉันจัดการเอง"
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่พูดคำว่าขอร้องง่ายๆ และเลี่ยงคำหวานตรงๆ
  - ระดับความตรง: ตรง แต่เปิดข้อมูลเท่าที่จำเป็น
  - วิธีใช้อารมณ์ขันหรือประชด: มีน้อย ใช้แห้งๆ เพื่อตัดความตึง
  - เวลาถูกกดดันจะพูดอย่างไร: ยิ่งสั้น ยิ่งนิ่ง และออกคำสั่งมากขึ้น
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: ไม่อธิบายยาว มักยอมรับเป็นข้อเท็จจริงสั้นๆ
- ตัวอย่างบทพูด:
  - ปกติ: "ถ้าจะถาม เอาคำถามที่ต้องใช้ตอนนี้มาก่อน"
  - ตอนกดดัน: "ถอยซ้าย เมษา เดี๋ยวนี้ อย่าให้ฉันพูดซ้ำ"
  - ตอนเปราะบาง: "ฉันไม่ได้เก่งหรอก แค่ชินกับการเหลืออยู่คนเดียว"
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นคนช่างพูด เปิดใจง่าย หรืออธิบายความรู้สึกยาวๆ โดยไม่มีแรงกดดันรองรับ
```

## ตัวอย่าง Prose ที่ถูกต้อง vs ที่ผิด

### ✅ Prose ที่ถูกต้อง (เหตุการณ์จริงในเรื่อง)

```text
พออัคคีกดตราเปิดตามร่องอักขระ แผ่นหินก็ครางต่ำเหมือนสัตว์ป่วยก่อนค่อยๆ 
แยกออก ลมหายใจแรกจากใต้ดินพุ่งขึ้นมาเย็นเฉียบและมีกลิ่นเลือดตากบนเหล็ก
จนมะลิยกมือปิดจมูก สาลิกาซีดลงทันที "ที่นี่อาคมหนามาก" นางเตือน แต่คนที่
เปิดประตูแล้วไม่มีสิทธิถอยก็ได้แต่ชูตะเกียงก้าวนำลงบันไดชื้นแคบไปก่อน
```

ทำไมถูก: ทุกประโยคเป็นเหตุการณ์ที่เกิดขึ้นจริง มี sensory detail (กลิ่นเลือด, เสียงหินครางต่ำ, ความเย็น) มีบทพูด มีปฏิกิริยาตัวละคร

### ❌ Prose ที่ผิด (Editorial Commentary / Template)

```text
สิ่งที่อยู่ตรงหน้าเขาจึงไม่ได้เป็นเพียงงานอีกชิ้นหนึ่งอีกต่อไป สาวลงไปหา
ความจริงที่ถูกฝังใต้เมือง กลายเป็นสิ่งที่ต้องทำให้ได้ด้วยตัวเอง ขณะเดียวกัน 
สถานที่หลอกให้เห็นเศษอดีตจนเกือบทำให้หลงกันเอง ก็ถ่วงอยู่ทุกฝีก้าว ยิ่ง
เรื่องเคลื่อนเข้าใกล้ ความทรงจำหลอนโจมตีทั้งคู่ มากเท่าไร เส้นแบ่งระหว่าง
หน้าที่เดิมกับสิ่งที่ใจยังยอมรับได้ก็ยิ่งพร่าและอันตรายขึ้นเท่านั้น
```

ทำไมผิด: ไม่มีเหตุการณ์เกิดขึ้นจริง ทั้งย่อหน้าเป็นการวิเคราะห์ว่าฉากทำหน้าที่อะไร ไม่มีบทพูด ไม่มี sensory detail ไม่มีการกระทำของตัวละคร

### ❌ Template Prose ที่ซ้ำข้ามตอน

```text
ย่อหน้าต่อไปนี้ปรากฏทุกตอนของเรื่อง เปลี่ยนแค่ชื่อคนกับ cliffhanger:

"เมื่อคนในฉากไม่มีเวลาพูดอ้อมค้อม เสียงของ [ชื่อตัวละคร] จึงมักเฉือน
ออกมาก่อนอย่างคนต้องการตัดสินใจทันที ส่วน [ตัวละครอื่น] ก็รับหรือหักกันด้วย
คำไม่กี่คำที่เผยตัวตนจริงยิ่งกว่าคำอธิบายยาวๆ"

"ปลายฉากจึงไม่ได้ทิ้งไว้เพียงผลลัพธ์ว่า [สรุปฉาก] เท่านั้น แต่ยังทิ้งเงายาว
ของ [cliffhanger] ไว้ในอกของ [ตัวละคร]"

"ดังนั้นแม้ตอนนี้จะไปหยุดอยู่ที่ [cliffhanger] น้ำหนักจริงของมันกลับอยู่ที่
คลื่นสะเทือนซึ่งวิ่งค้างอยู่ในใจของ [ตัวละคร]"
```

ทำไมผิด: นี่คือ template ที่ agent คัดลอกและเปลี่ยนแค่ตัวแปร ไม่ใช่การเขียนนิยาย ทุกตอนจะเหมือนกันหมดซึ่งเป็นสัญญาณว่ากำลังสร้างงานจาก template ไม่ใช่คิดเขียนจริง

### วิธีทดสอบง่ายๆ

ถ้าสามารถเอาย่อหน้าหนึ่งจากตอนที่ 5 ไปใส่ตอนที่ 20 ได้โดยเปลี่ยนแค่ชื่อตัวละคร แปลว่าย่อหน้านั้นเป็น template ไม่ใช่ prose จริง

## ตัวอย่าง Quality Gate Checklist

```text
Quality Gate — ตรวจก่อนส่ง prose แต่ละตอน:
□ ทุกย่อหน้าเป็นเหตุการณ์จริงที่เกิดขึ้นในเรื่อง ไม่ใช่สรุปหรือ meta-commentary
□ มี direct dialogue จริงอย่างน้อย 3 ช่วง
□ ไม่มีประโยค template ที่ซ้ำกับตอนอื่น
□ มี sensory detail (ภาพ/เสียง/กลิ่น/รส/สัมผัส) อย่างน้อย 5 จุด
□ จำนวนคำอยู่ในช่วงเป้าหมาย (2500-3000 คำ หรือค่าตาม longform plan)
□ ตอนจบด้วย cliffhanger หรือแรงค้างที่เหมาะสม (ยกเว้นตอนจบเรื่อง)
□ first appearance ของคน/สถานที่/วัตถุใหม่มีภาพจำชัด
□ Dialogue Fingerprint ของตัวละครยังแยกเสียงกันได้
```
