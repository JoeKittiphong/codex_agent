# Character Bible

## ตัวละครหลัก

### ขุนอัคคี
- บทบาทต่อเรื่อง: ตัวเอก
- Archetype / หน้าที่ในพล็อต: มือปราบของรัฐที่ต้องกลายเป็นผู้คืนความจริง
- อายุ / ภาพลักษณ์: ราว 29 ปี รูปร่างสูงเพรียว แข็งแรงแบบคนฝึกดาบทุกวัน ดวงตาคล้ำเหมือนอดนอนเรื้อรัง
- ภาพจำแรกตอนเปิดตัว: ชายหนุ่มในชุดมือปราบสีเข้มที่ยืนท่ามกลางเลือดและฝนอย่างนิ่งเกินมนุษย์ เหมือนความหนาวไม่เคยแตะถึงกระดูก
- ภาพลักษณ์ที่คนอื่นเข้าใจ: เย็นชา ซื่อสัตย์ต่อคำสั่ง ไร้เมตตาเมื่อจำเป็น
- ตัวตนจริงลึกลงไป: คนที่ชินกับการกดความรู้สึกเพราะกลัวว่าถ้ารู้สึกมาก เขาจะพังจากความทรงจำของตัวเอง
- แกนตัวตน / ความขัดแย้งในตัวเอง: อยากรู้ความจริงเรื่องพ่อ แต่กลัวว่าความจริงนั้นจะพิสูจน์ว่าตัวเองรับใช้สิ่งชั่วร้ายมาตลอด
- เป้าหมายภายนอก: เปิดโปงกรมอาลักษณ์ ช่วยสาลิกา และหยุดยันต์มหาลืม
- ความต้องการภายใน: ยอมรับว่าความผูกพันไม่ใช่จุดอ่อนเสมอไป
- ความกลัวหลัก: กลายเป็นอาวุธของคนอื่นเหมือนบิดา หรือเลวพอๆ กับระบบที่ตัวเองรับใช้
- ความเชื่อผิดพลาด: ถ้าตัดความรู้สึกทิ้ง เขาจะปกป้องคนอื่นได้ดีกว่า
- บาดแผล / ปม: บิดาหายไปพร้อมตราบาปกบฏ ทำให้เขาอยู่กับความอับอายและคำถามที่ไม่มีวันถามใคร
- กลไกป้องกันตัว: พูดสั้น ทำหน้าที่ก่อนความรู้สึก และหลีกเลี่ยงคำอธิบายเรื่องตัวเอง
- ความลับ: เขาเริ่มสงสัยมานานแล้วว่าพิธีลบความจำของรัฐไม่สะอาดอย่างที่สอนกัน
- จุดอ่อน: ชอบแบกทุกอย่างไว้คนเดียว และเมื่อกลัวจะควบคุมคนอื่นผ่านคำสั่ง
- จุดแข็ง: วินัยสูง อ่านสนามต่อสู้ไว และยอมลงมือเมื่อทุกคนลังเล
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่ฆ่าเด็ก ไม่ทรมานผู้บริสุทธิ์ และท้ายที่สุดไม่ยอมลบพยานเพื่อปิดความจริง
- จุดเปราะบาง / trigger: เรื่องพ่อ ผู้ถูกลบความจำจนจำคนรักไม่ได้ เด็กที่กลายเป็นเครื่องมือของรัฐ
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: คุมสถานการณ์ด้วยความนิ่ง การตัดสินใจเร็ว และการวางตัวให้คนอื่นเดาใจยาก
- ภาษากายหรือพฤติกรรมติดตัว: ชอบกำด้ามดาบเบาๆ เวลาคิด เลี่ยงสบตานานเมื่อถูกถามเรื่องอดีต และยืนหันไหล่เข้าหาทางหนีเสมอ
- ความสัมพันธ์สำคัญ: สาลิกาทำให้เขาเห็นว่าความจริงต้องมีคนจำร่วมกัน, หลวงวิจิตรคือพ่อแทนที่แบบผิดรูป, บิดาคือบาดแผลที่ยังหายใจอยู่
- Story points ที่มีบทบาท: 1, 3, 5-7, 10, 13-27
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: อาวุธของรัฐ -> ผู้หลบหนีที่เริ่มคุ้มครองความทรงจำคนอื่น -> คนแปลกหน้าผู้คืนความจริง
- Dialogue Fingerprint:
  - ระดับภาษา: สุภาพแข็ง เย็น และคม
  - จังหวะประโยค: สั้น หยุดพอดี ไม่อธิบายเกินจำเป็น
  - คำที่ชอบใช้: "พอ" "เอาที่จำเป็น" "ฉันจัดการเอง"
  - คำที่ไม่ใช้ / คำที่เลี่ยง: เลี่ยงคำหวาน เลี่ยงคำขอร้องตรงๆ
  - ระดับความตรง: ตรง แต่บอกเฉพาะที่จำเป็น
  - วิธีใช้อารมณ์ขันหรือประชด: แห้งมาก ใช้น้อย เพื่อหยุดความตึง
  - เวลาถูกกดดันจะพูดอย่างไร: สั้นลง นิ่งลง และออกคำสั่งชัดขึ้น
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: มักยอมรับเป็นข้อเท็จจริงสั้นๆ ไม่พูดฟูมฟาย
- ตัวอย่างบทพูด:
  - ปกติ: "ถ้าจะถาม ถามสิ่งที่ทำให้เรารอดคืนนี้ก่อน"
  - ตอนกดดัน: "ถอยหลังหนึ่งก้าว เดี๋ยวนี้ ถ้ายังอยากมีความจำเหลือพอจะกลับบ้าน"
  - ตอนเปราะบาง: "ฉันไม่กลัวความจริงหรอก...ฉันกลัวว่ามันจะอธิบายฉันได้หมดต่างหาก"
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นคนพูดยาว เปิดใจง่าย หรือโรแมนติกโจ่งแจ้งโดยไม่มีแรงผลักทางอารมณ์รองรับ

### สาลิกา
- บทบาทต่อเรื่อง: นางเอกคู่ขับเคลื่อน / ผู้เห็นความทรงจำ / ผู้เปิดโลกอีกฝั่งของความจริง
- Archetype / หน้าที่ในพล็อต: คนอ่านบาดแผลของโลกและบังคับให้ตัวเอกเลิกหลบอารมณ์
- อายุ / ภาพลักษณ์: ราว 25 ปี งามแบบนุ่มนวล สายตาคมใสกว่าคนปกติ เมื่อใช้เนตรทิพย์ม่านตาจะมีประกายเงินแดง
- ภาพจำแรกตอนเปิดตัว: นางรำในแสงตะเกียงที่นิ้วมือเปื้อนเลือดเพียงหยดเดียว แต่สีหน้ากลับนิ่งราวกำลังฟังเสียงกรีดร้องที่คนอื่นไม่ได้ยิน
- ภาพลักษณ์ที่คนอื่นเข้าใจ: อ่อนหวาน อ่อนโยน ใช้ศิลปะรับใช้วัง
- ตัวตนจริงลึกลงไป: เฉียบคม ดื้อเงียบ และเกลียดการถูกใช้เป็นเครื่องมือพอๆ กับอัคคี
- แกนตัวตน / ความขัดแย้งในตัวเอง: อยากช่วยคนด้วยพรสวรรค์ของตน แต่กลัวว่ายิ่งมองเห็นความทรงจำมากเท่าไร ตัวเองจะไม่เหลือที่ยืนในความจริงของตัวเอง
- เป้าหมายภายนอก: ตามรอยความทรงจำเลือด เปิดโปงความจริง และรอดจากการถูกทำให้เป็นเครื่องสังเวย
- ความต้องการภายใน: เชื่อว่าตัวเองมีค่ามากกว่าการเป็นภาชนะของสายตาคนอื่น
- ความกลัวหลัก: ถูกกลืนหายโดยความทรงจำของผู้อื่นจนลืมว่าเสียงของตัวเองเป็นอย่างไร
- ความเชื่อผิดพลาด: คนอย่างเธอมีค่าเมื่อมองเห็นประโยชน์ให้คนอื่นเท่านั้น
- บาดแผล / ปม: ถูกวังและกรมอาลักษณ์ใช้พรสวรรค์มาตลอด โดยไม่เคยถามว่าเธออยากเห็นหรือไม่
- กลไกป้องกันตัว: ใช้ความสุภาพและรอยยิ้มบางๆ ปิดความโกรธ
- ความลับ: เธอเคยเห็นเศษความทรงจำของอัคคีมาก่อนพบตัวจริง และรู้ว่าเขาไม่ใช่คนไร้หัวใจอย่างที่เมืองลือ
- จุดอ่อน: ฝืนตัวเองเกินขีดเมื่อจะช่วยใครสักคน
- จุดแข็ง: รับรู้เบาะแสจากสิ่งเล็กน้อย อ่านคนเก่ง และรักษาสติในฉากหลอนจัดได้ดี
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่อ่านความทรงจำคนบริสุทธิ์เพียงเพื่อสนองความอยากรู้
- จุดเปราะบาง / trigger: เสียงร้องขอความช่วยเหลือของคนที่ถูกบังคับเงียบ และเลือดเด็ก
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ใช้ความนุ่มนวลล้วงข้อมูล ใช้ความเงียบทำให้คนอีกฝ่ายเปิดช่อง และเมื่อจำเป็นจะพูดแทงตรงกว่าที่คนคาด
- ภาษากายหรือพฤติกรรมติดตัว: ใช้นิ้วแตะข้อมือตัวเองก่อนอ่านเลือด กลืนน้ำลายช้าลงเมื่อฝืนเนตรทิพย์ และชอบมองหน้าคนตอนเขาโกหก
- ความสัมพันธ์สำคัญ: อัคคีคือคนแรกที่เริ่มมองเธอเป็นมนุษย์ก่อนเครื่องมือ, หลวงวิจิตรต้องการเธอในฐานะสังเวย, บิดาอัคคีกลายเป็นเงาความจริงที่เธอพยายามช่วยปลดปล่อย
- Story points ที่มีบทบาท: 8-9, 12-13, 15-25, 27
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ผู้ถูกใช้ -> ผู้ร่วมตัดสินใจและเปิดโปง -> ผู้รอดที่แบกความจริงต่อจากผู้สูญเสีย
- Dialogue Fingerprint:
  - ระดับภาษา: สุภาพ ลื่น หวานแต่ไม่อ่อนแรง
  - จังหวะประโยค: เป็นคลื่น มีจังหวะเว้นให้คิดตาม
  - คำที่ชอบใช้: "ท่าน" "บางที" "หรือว่า"
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่ใช้คำหยาบตรงๆ และไม่ออกคำสั่งแรงๆ ถ้าไม่จำเป็น
  - ระดับความตรง: ปกติอ้อมนุ่ม แต่เรื่องความจริงจะตรงขึ้นเรื่อยๆ
  - วิธีใช้อารมณ์ขันหรือประชด: ประชดเบาแบบยิ้มไม่ถึงตา
  - เวลาถูกกดดันจะพูดอย่างไร: หายใจช้าลง พูดนุ่มกว่าเดิม แต่เลือกคำคมขึ้น
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: พูดชัดแต่เบา เหมือนยื่นมีดด้ามเรียบให้คนฟังจับเอง
- ตัวอย่างบทพูด:
  - ปกติ: "ท่านมักทำหน้าเหมือนไม่เชื่อใคร แต่เลือดของท่านไม่เคยโกหกข้าสักครั้ง"
  - ตอนกดดัน: "ถ้าท่านจะฝืนเข้าไปคนเดียว ก็อย่างน้อยอย่าทำให้ความตายของข้ากลายเป็นของฟรี"
  - ตอนเปราะบาง: "บางความทรงจำไม่ยอมออกจากมือ ข้าไม่รู้แล้วว่าที่สั่นอยู่เป็นเลือดของใครหรือของข้าเอง"
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามทำให้เธอเป็นเพียงคนสวยผู้ต้องให้ช่วยตลอด หรือเป็นเครื่องอ่านเบาะแสไร้ราคาที่จ่าย

### หลวงวิจิตร
- บทบาทต่อเรื่อง: ตัวร้ายหลัก
- Archetype / หน้าที่ในพล็อต: ผู้ปกครองที่เชื่อว่าการลบความจริงคือเมตตาแบบมีอำนาจ
- อายุ / ภาพลักษณ์: วัยห้าสิบปลาย แต่งกายเนี้ยบ ไร้ฝุ่น ไร้คราบ รอยยิ้มบางเหมือนเส้นมีด
- ภาพจำแรกตอนเปิดตัว: ชายชราผิวเรียบสะอาดเกินจริงในห้องที่มีกลิ่นกระดาษเก่า เขาแทบไม่ต้องขึ้นเสียง แค่ขยับนิ้วคนทั้งห้องก็เงียบ
- ภาพลักษณ์ที่คนอื่นเข้าใจ: ขุนนางสุขุม มีเหตุผล คุ้มครองบ้านเมืองด้วยสติ
- ตัวตนจริงลึกลงไป: หมกมุ่นกับการควบคุมจนมองมนุษย์เป็นวัตถุดิบของความสงบ
- แกนตัวตน / ความขัดแย้งในตัวเอง: เกลียดความวุ่นวายจากอดีต จนสร้างความโหดร้ายยิ่งกว่าเพื่อป้องกันมัน
- เป้าหมายภายนอก: ใช้ยันต์มหาลืมควบคุมพระนครทั้งเมือง
- ความต้องการภายใน: บดขยี้ความกลัวอดีตที่ครั้งหนึ่งเขาเคยควบคุมอะไรไม่ได้
- ความกลัวหลัก: ความจริงจะปลุกประชาชนให้ลุกฮือและทำให้โลกกลับสู่ความโกลาหล
- ความเชื่อผิดพลาด: มนุษย์ไม่สมควรถือความทรงจำของตัวเองทั้งหมด เพราะความจริงทำให้คนโง่ใช้เสรีภาพผิดทาง
- บาดแผล / ปม: เคยผ่านสงครามกลางเมืองหรือเหตุจลาจลที่คร่าชีวิตคนจำนวนมาก จนเชื่อว่าความทรงจำคือเชื้อไฟ
- กลไกป้องกันตัว: อธิบายความรุนแรงด้วยภาษาสุภาพและเหตุผลสูงส่ง
- ความลับ: เขาอยู่เบื้องหลังการสร้างโรงงานผีและการจับบิดาอัคคีมาเป็นนักรบทองคำ
- จุดอ่อน: มั่นใจในตรรกะตัวเองจนประเมินพลังของความผูกพันต่ำเกินไป
- จุดแข็ง: วางแผนระยะยาว เก่งชี้นำคน และรู้จักใช้ความผิดบาปของผู้อื่นมาคุมเกม
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: แทบไม่มีเส้นศีลธรรมที่ไม่ยอมข้าม หากผลลัพธ์คือระเบียบที่เขาต้องการ
- จุดเปราะบาง / trigger: การถูกทวงถามเรื่องอดีตที่เขาเองอยากลืม
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ใช้คำสุภาพ คำสั่งนุ่ม และระบบราชการเป็นมีด
- ภาษากายหรือพฤติกรรมติดตัว: ชอบลูบขอบกระดาษหรือโต๊ะให้ตรง ราวกับโลกต้องเข้าที่ตามนิ้วเขา
- ความสัมพันธ์สำคัญ: มองอัคคีเป็นผลงานที่เกือบสมบูรณ์, มองสาลิกาเป็นทรัพยากร, มองบิดาอัคคีเป็นอาวุธที่ริบมาจากอดีต
- Story points ที่มีบทบาท: 2, 4, 6, 15-16, 20, 24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ผู้กำกับความสงบจากเงามืด -> ผู้เร่งลบทั้งเมือง -> ผู้พังทลายเพราะความจริงย้อนกลับเข้าหาตัวเอง
- Dialogue Fingerprint:
  - ระดับภาษา: สุภาพสูง ราชการจัด
  - จังหวะประโยค: เรียบ ยาวพอดี มีจังหวะสอน
  - คำที่ชอบใช้: "เพื่อส่วนรวม" "เรียบร้อย" "จำเป็น"
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่พูดคำว่าฆ่าตรงๆ ชอบใช้คำว่าเก็บ กำกับ ปรับระเบียบ
  - ระดับความตรง: อ้อมอย่างมีอำนาจ
  - วิธีใช้อารมณ์ขันหรือประชด: ยิ้มบางแล้วพูดเหมือนชม แต่จริงคือเหยียด
  - เวลาถูกกดดันจะพูดอย่างไร: ยิ่งสุภาพ ยิ่งเย็น
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: ไม่ขอโทษ เขาจะอธิบายแทน
- ตัวอย่างบทพูด:
  - ปกติ: "ความจริงที่เกินมือประชาชน มิใช่ความจริง หากเป็นอาวุธ"
  - ตอนกดดัน: "ขุนอัคคี เจ้ากำลังเข้าใจคำว่าเมตตาผิดไปมาก"
  - ตอนเปราะบาง: "ท่านไม่รู้หรอก...เมืองที่จำทุกอย่างได้พร้อมกัน มันเผาคนทั้งเมืองได้เร็วเพียงใด"
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามทำให้ตะโกนพร่ำเพรื่อหรือกลายเป็นคนบ้าคลั่งไร้ตรรกะเร็วเกินไป

### ขุนภาสกร / นักรบทองคำ
- บทบาทต่อเรื่อง: บิดาของอัคคี / บาดแผลมีชีวิต / กระจกของอนาคตที่ตัวเอกกลัวจะเป็น
- Archetype / หน้าที่ในพล็อต: พ่อที่หายไปและกลับมาในฐานะอาวุธไร้วิญญาณ
- อายุ / ภาพลักษณ์: ชายวัยห้าสิบต้น ร่างสูงใหญ่เต็มบาดแผล ผิวหนังมีรอยยันต์ทองกินลามเหมือนโลหะฝังใต้เนื้อ
- ภาพจำแรกตอนเปิดตัว: นักรบทองคำไร้หน้าที่ขยับดาบเพียงครั้งเดียวก็ทำให้อากาศทั้งห้องเหมือนแตกเป็นเศษกระจก
- ภาพลักษณ์ที่คนอื่นเข้าใจ: อาวุธลับไร้ใจของกรมอาลักษณ์
- ตัวตนจริงลึกลงไป: คนที่ถูกพรากทั้งชื่อ ความจำ และเจตจำนง แต่ยังเหลือเศษสัญชาตญาณปกป้องลูก
- แกนตัวตน / ความขัดแย้งในตัวเอง: ร่างถูกบังคับรับใช้ศัตรู แต่วิญญาณพยายามต่อต้านเงียบๆ
- เป้าหมายภายนอก: ในระดับสติชั่ววูบ เขาต้องการหยุดพิธีและไม่ให้อัคคีกลายเป็นเหมือนตน
- ความต้องการภายใน: ได้ตายอย่างมนุษย์ ไม่ใช่อาวุธ
- ความกลัวหลัก: ลูกชายจะสืบทอดชะตาทาสอาคม
- ความเชื่อผิดพลาด: ถ้าหายไปจากชีวิตลูก ลูกอาจปลอดภัยกว่า
- บาดแผล / ปม: ถูกจับ ป้ายสี และรีดอาคมจนกลายเป็นเครื่องจักรสงคราม
- กลไกป้องกันตัว: เงียบ ความทรงจำแตกเป็นเศษ และใช้ร่างสู้แทนคำพูด
- ความลับ: เขาแอบทิ้งร่องรอยรอยสักไว้ในศพเพื่อเรียกลูกเข้าหาความจริง
- จุดอ่อน: สติไม่มั่นคง ถูกยันต์ควบคุมเมื่อแกนพิธีกระตุ้น
- จุดแข็ง: ฝีมือดาบสูงสุดรุ่นหนึ่ง และร่างทนพลังอาฆาตผิดมนุษย์
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: เมื่อสติกลับมา เขาจะไม่ปล่อยให้ลูกถูกใช้เป็นอาวุธต่อจากตน
- จุดเปราะบาง / trigger: เสียงเรียกชื่อจากอัคคี คาถาที่เคยสอนลูก และหน้ากากทองคำ
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ในสภาพอาวุธ เขาใช้การโจมตีตรงหนักและกดพื้นที่; ในสติชั่ววูบ เขาเลือกกันลูกก่อนชนะ
- ภาษากายหรือพฤติกรรมติดตัว: เมื่อได้สติ นิ้วจะสั่นเบาๆ ก่อนกำด้ามดาบกลับด้านเพื่อป้องกัน ไม่ใช่ฆ่า
- ความสัมพันธ์สำคัญ: อัคคีคือจุดยึดสุดท้ายของความเป็นมนุษย์ในตัวเขา
- Story points ที่มีบทบาท: 5, 14, 21, 25
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: เงาปริศนา -> อาวุธของศัตรู -> พ่อที่ได้เลือกครั้งสุดท้าย
- Dialogue Fingerprint:
  - ระดับภาษา: เมื่อได้สติใช้คำสั้น หนัก และเก่า
  - จังหวะประโยค: ขาดๆ เหมือนจำเสียงตัวเองไม่ถนัด
  - คำที่ชอบใช้: "อย่าเป็นเหมือนข้า" "หนี" "จำไว้"
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่มีถ้อยคำฟุ่มเฟือย
  - ระดับความตรง: ตรงมาก
  - วิธีใช้อารมณ์ขันหรือประชด: ไม่มี
  - เวลาถูกกดดันจะพูดอย่างไร: ยิ่งสั้นและแทบเป็นคำเดี่ยว
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: ใช้การกระทำแทนคำมากกว่าพูด
- ตัวอย่างบทพูด:
  - ปกติ: "ดาบ...ไม่ผิด คนใช้มันต่างหาก"
  - ตอนกดดัน: "อัคคี ถอย!"
  - ตอนเปราะบาง: "พ่อจำเจ้าได้...เท่านี้ก็พอแล้ว"
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามฟื้นสติยาวต่อเนื่องจนลดน้ำหนักโศกนาฏกรรมการถูกทำให้เป็นอาวุธ

## ตัวละครรอง

### แม่ครูพวงคำ
- บทบาทต่อเรื่อง: ผู้ดูแลเครือข่ายคนความจำพร่า / mentor ฝั่งศีลธรรม
- ความสัมพันธ์กับตัวละครหลัก: เป็นผู้ใหญ่ไม่ไว้ใจอัคคีในตอนแรก แต่ค่อยยอมรับเมื่อเห็นว่าเขาเลิกเป็นมือรัฐจริง
- หน้าที่ต่อพล็อต: ช่วยพยุงช่วงกลางเรื่อง ให้ที่พักพิงและข้อมูลเรื่องผลตกค้างของอาคมลบความจำ
- Dialogue Fingerprint แบบย่อ: พูดช้า เปรียบความทรงจำกับด้าย ผ้า และรอยเย็บ
- สิ่งที่ทำให้คนอ่านจำได้: มือที่คอยเย็บผ้าขาดให้คนอื่น ขณะพูดเรื่องความทรงจำแตกเป็นฝอย

### หมื่นชยุต
- บทบาทต่อเรื่อง: นายทหารมือรองของหลวงวิจิตร / คู่ไล่ล่าภาคสนาม
- ความสัมพันธ์กับตัวละครหลัก: เคยร่วมงานกับอัคคี เคารพฝีมือแต่เลือกภักดีต่อระเบียบ
- หน้าที่ต่อพล็อต: เพิ่มแรงกดดันฝั่งรัฐและสะท้อนเส้นทางที่อัคคีอาจเป็นถ้าไม่เปลี่ยน
- Dialogue Fingerprint แบบย่อ: พูดชัด แข็ง ใช้ภาษาทหาร ไม่ประชด
- สิ่งที่ทำให้คนอ่านจำได้: เดินเป็นจังหวะเหมือนกลองสนามรบและไม่เคยถอดถุงมือหนัง

### เด็กหญิงมะลิ
- บทบาทต่อเรื่อง: ผู้รอดจากหมู่บ้านชายแดน
- ความสัมพันธ์กับตัวละครหลัก: คือพยานที่อัคคีเลือกไม่ลบความจำ และกลายเป็นเหตุผลจับต้องได้ของการทรยศรัฐ
- หน้าที่ต่อพล็อต: ทำให้เดิมพันเรื่องความทรงจำไม่เป็นนามธรรม
- Dialogue Fingerprint แบบย่อ: พูดตรง ซื่อ และมีช่องว่างของคนจำอะไรได้ไม่ครบ
- สิ่งที่ทำให้คนอ่านจำได้: ชอบถามซ้ำว่าหน้าคนตายหายไปไหนจากหัวตัวเอง
