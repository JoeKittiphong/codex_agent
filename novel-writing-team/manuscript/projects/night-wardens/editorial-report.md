# Editorial Report

- ขอบเขตที่ตรวจ: draft 1 rebuild ตอน 1-24 + เอกสารโครงทั้งหมด
- ภาพรวม: โครงเรื่องยังแข็งแรง และ prose ชุดใหม่อ่านเป็นนิยายจริงได้แล้วในระดับ draft 1 มีฉาก บทพูด และแรงส่งต่อเนื่องกว่ารุ่นก่อนชัดเจน แต่ยังควรทำ editorial pass รอบจริงอีกครั้งก่อนเข้า rewrite pass เพื่อเก็บความสม่ำเสมอของน้ำเสียง ความยาวตอน และน้ำหนักฉากสำคัญ

## จุดแข็ง
1. premise, world rules, character roles และเส้นก่อตั้งทีมทำงานร่วมกันชัด
2. ตอน 1-24 ชุดใหม่มี scene progression และบทพูดที่ใช้ได้จริงกว่ารุ่นก่อน
3. ภาพชีวิตแรงงานกลางวันกับสงครามฝันกลางคืนเริ่มมีเอกลักษณ์ของเรื่องชัดขึ้น

## ปัญหาหลัก
1. [ระดับ: กลาง] ความยาวและน้ำหนักของแต่ละตอนยังไม่สม่ำเสมอ บางตอนสั้นกว่าศักยภาพของฉากสำคัญ
2. [ระดับ: กลาง] บางตอนช่วงกลาง-ปลายเรื่องยังควรขยายบทสนทนาและ beat อารมณ์เพิ่ม โดยเฉพาะตอน 11-12 และ 18-23
3. [ระดับ: ต่ำ] ควรเกลาการไหลของ POV และจังหวะบรรยายให้ลื่นขึ้นอีกก่อนเข้ารอบ rewrite

## จุด continuity ที่ต้องแก้
1. รักษาผลสะสมของการอดนอนให้มีผลจริงต่อร่างกายและการตัดสินใจต่อเนื่องทุกตอน
2. คุมเส้นเจ็ดคืนของพาหะและเวลาของพาหะหลักให้ชัดใน rewrite รอบถัดไป
3. รักษาความค่อยเป็นค่อยไปของทีมจากผู้รอดสู่ผู้พิทักษ์ไม่ให้ข้ามขั้น

## ฉากหรือช่วงที่ควรตัด/รวม
1. ยังไม่จำเป็นต้องตัดเชิงโครงสร้างตอนนี้
2. ถ้าจะกระชับในอนาคต ให้ดูฉากอธิบายข้อมูลซ้ำในช่วง 6-8 และ 11-12 ก่อน

## คำแนะนำเชิงลงมือแก้
1. ทำ editorial pass ราย batch 1-4, 5-8, 9-12, 13-16, 17-20, 21-24
2. เก็บบทพูดและภาษากายให้แตกเสียงตัวละครชัดขึ้นอีก
3. จากนั้นค่อยทำ rewrite pass รอบจริงทั้งเรื่อง

## ลำดับการแก้ที่แนะนำ
1. editorial pass รอบใหม่
2. rewrite pass
3. final continuity + word-count audit
4. editorial polish
