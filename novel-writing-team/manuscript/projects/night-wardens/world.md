# World Bible

- แกนโลก:
  - โลกจริงคือเมืองอุตสาหกรรมร่วมสมัยที่คนจำนวนมากนอนน้อย ทำงานเป็นกะ และใช้ชีวิตผ่านหน้าจอ
  - โลกฝันหรือ “แดนนิทรา” เป็นชั้นความจริงที่ก่อตัวจากความทรงจำ อารมณ์ และสติของมนุษย์

- กติกาหลัก:
  1. ทุกคนเข้าสู่แดนนิทราทุกคืน แต่คนส่วนใหญ่จำไม่ได้เมื่อตื่น
  2. “สติในฝัน” คือความสามารถในการรู้ตัวว่ากำลังฝันและบังคับเจตนาได้ ยิ่งชัด ยิ่งมีพลัง
  3. ฝันร้ายเป็นกลุ่มก้อนอารมณ์เสียรูป เมื่อรวมตัวหนาแน่นจะเกิด “มวลทมิฬ” และอาจพัฒนาเป็นเจ้าแก่น
  4. เจ้าแก่นบางตนสามารถยึดเกาะ “พาหะ” ในโลกจริงได้ โดยเกาะผ่านรอยแตกทางใจ การอดนอน หรือการเสพความกลัวซ้ำๆ
  5. การช่วยพาหะต้องใช้การเชื่อมใกล้ชิดกับร่างจริง แล้วเข้าไปสู้กับแก่นฝันร้ายภายในภูมิฝันของพาหะ

- สถานที่สำคัญ:
  1. โรงงานชิ้นส่วนโลหะในนิคมอุตสาหกรรมทิศตะวันออก ที่ภาคินทำงาน
  2. หอพักคนงาน “หอแสงเดือน” สถานที่เกิดคดีแรก
  3. แดนนิทราเขตโรงงาน สนามรบประจำของภาคินช่วงต้นเรื่อง
  4. คลินิกการนอน “นิทราไลฟ์” ฉากบังหน้าแห่งเครือข่ายฝันร้าย
  5. ห้างร้างริมเมืองซึ่งกลายเป็นรังรวมมวลทมิฬ
  6. ปราการกลางฝัน “มหานครไร้รุ่ง” ในไคลแมกซ์

- ระบบอำนาจ / เวท / เทคโนโลยี:
  - อาวุธในฝันเกิดจากภาพแทนที่ลึกที่สุดในใจผู้ใช้
  - คาถาหรืออิทธิฤทธิ์คือการใช้น้ำหนักเจตนา สัญลักษณ์ส่วนตัว และความทรงจำขับพลัง
  - มือถือ อินเทอร์เน็ต ฟีดข่าว และห้องแชตมีผลต่อรูปทรงของฝันร้าย เพราะช่วยหมักความกลัวหมู่
  - ไม่มีใครใช้ปืนในฝันได้เต็มประสิทธิภาพ หากจิตไม่เชื่อจริงพอ อาวุธสมัยใหม่จึงมักเสถียรน้อยกว่าอาวุธเชิงสัญลักษณ์

- กลุ่มอิทธิพล:
  1. มวลทมิฬเร่ร่อน ฝันร้ายระดับต่ำที่ล่าอารมณ์สดใหม่
  2. เจ้าแก่นและก้อนฝันร้ายระดับสูงที่ควบคุมพาหะได้
  3. เครือข่ายคลินิกนิทราไลฟ์ ซึ่งถูกฝันร้ายใช้เป็นทางเลือกพาหะและข้อมูลคนเสี่ยง
  4. หน่วยพิทักษ์ราตรี ซึ่งก่อตัวปลายเรื่องจากผู้รอดที่ตื่นรู้

- วัฒนธรรมและวิถีชีวิต:
  - โลกจริงเต็มไปด้วยคนกะกลางคืน พนักงานคอลเซ็นเตอร์ แมสเซนเจอร์ พยาบาล รปภ. และแรงงานที่เวลานอนกระจัดกระจาย
  - คนจำนวนมากพึ่งมือถือเพื่อกล่อมตัวเองหลับ แต่สิ่งนี้ยิ่งเปิดรอยแตกให้ฝันร้ายบางประเภท

- เศรษฐกิจและทรัพยากร:
  - ความยากจน เวลาไม่พอ และภาระครอบครัวเป็นแรงกดหลักของโลกจริง
  - ทรัพยากรในโลกฝันคือสติ ความทรงจำ ความสัมพันธ์ และสิ่งยึดโยงจากโลกจริง

- ภัยคุกคามหลัก:
  - “มอรัส” เจ้าแก่นฝันร้ายระดับสูง ผู้รวมกินความกลัวจากการนอนน้อยของคนทั้งเมือง
  - หากมันตั้งหลักในพาหะหลักได้สำเร็จ เมืองจะเข้าสู่ภาวะคนหลับไม่ลึก ตื่นไม่เต็ม และถูกดูดกลืนง่ายขึ้นทุกคืน

- ข้อจำกัดที่ส่งผลต่อพล็อต:
  - นักสู้ในฝันยิ่งใช้พลังเกินตัว ร่างจริงยิ่งทรุด
  - ถ้าจิตแตกหรือความกลัวครอบงำ อาวุธจะเสียรูป
  - การตายในฝันไม่ฆ่าร่างจริงทันทีเสมอ แต่ทำให้สติแตกหัก บางคนไม่กลับมาเป็นเหมือนเดิม

- จุดในเรื่องที่จะใช้ข้อมูลโลกเหล่านี้:
  - ตอน 1-4: ตั้งกฎพื้นฐานของภาคินและพาหะ
  - ตอน 5-12: ขยายความเรื่องผู้รอดและอาวุธในฝัน
  - ตอน 13-20: เปิดเครือข่ายพาหะและมหานครไร้รุ่ง
  - ตอน 21-24: ใช้กฎทั้งหมดรวมกันในศึกสุดท้ายและการตั้งหน่วยพิทักษ์ราตรี
