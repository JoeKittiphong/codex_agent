# Character Bible

## ตัวละคร: ภาคิน จันทร์เพ็ญ
- บทบาทต่อเรื่อง: protagonist
- Archetype / หน้าที่ในพล็อต: คนงานผู้เป็นประตูสู่แดนนิทรา / นักล่าเดี่ยวที่ต้องเรียนรู้การเป็นหัวหน้าทีม
- อายุ / ภาพลักษณ์: 26 ปี, ผอมแข็ง ไหล่ล้า มือด้านจากงานโรงงาน ใต้ตาคล้ำเรื้อรัง
- เป้าหมายภายนอก: ช่วยพาหะที่ถูกฝันร้ายยึดร่างและหยุดเครือข่ายมอรัส
- ความต้องการภายใน: ยอมรับว่าการพึ่งพาผู้อื่นไม่ใช่ความอ่อนแอ
- บาดแผล / ปม: เคยเสียพ่อจากอุบัติเหตุโรงงานและเชื่อว่าคนที่ช้าหรืออ่อนแอจะถูกทิ้งไว้เสมอ
- ความลับ: ตอนเด็กเคยตกอยู่ในอาการโคม่าสั้นๆ ทำให้เริ่มจำโลกฝันได้
- จุดอ่อน: แบกทุกอย่างคนเดียว, ไม่ขอความช่วยเหลือ, มีแนวโน้มทำลายตัวเอง
- จุดแข็ง: อดทนสูง, สติในฝันมั่นคง, เมตตาแม้ไม่พูดมาก
- ความสัมพันธ์สำคัญ: ญาดาเป็นคู่โต้แย้งทางความคิด, รวิเป็นคนท้าชน, วรันยาเป็นคนย้ำเรื่องการประคองชีวิต, ธเนศเป็นหลักค้ำภาคพื้น
- Story points ที่มีบทบาท: เด่นแทบทุก point โดยเฉพาะ 4, 13, 17-24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: นักล่าเดี่ยวที่คิดว่าต้องรอดเอง -> คนที่เริ่มมีพวกแต่ยังไม่ยอมพึ่ง -> หัวหน้าทีมที่เชื่อในสติร่วม
- น้ำเสียงการพูด: สั้น ตรง สุภาพแบบคนไม่ชอบเป็นภาระใคร
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามพูดเก่งพร่ำเพรื่อหรือกลายเป็นฮีโร่ปากสวยโดยไม่มีความเหนื่อยจริง

## ตัวละคร: ญาดา บุญส่ง
- บทบาทต่อเรื่อง: ally / brains / first awakened survivor
- Archetype / หน้าที่ในพล็อต: คนแรกที่พิสูจน์ว่าผู้รอดสามารถหวนกลับมาสู้ได้
- อายุ / ภาพลักษณ์: 24 ปี, พนักงานคอลเซ็นเตอร์ หน้าซีดจากการอดนอน ดวงตาไวต่อรายละเอียด
- เป้าหมายภายนอก: เอาคืนฝันร้ายที่เกือบพรากสติไป และหาต้นตอของคดีทั้งหมด
- ความต้องการภายใน: เลิกโทษตัวเองที่รับฟังความทุกข์คนอื่นจนใจพัง
- บาดแผล / ปม: งานรับสายร้องเรียนและคำด่าซ้ำๆ ทำให้เธอเชื่อว่าตัวเองเป็นถังขยะของโลก
- ความลับ: เธอจำเสียงเรียกของมอรัสได้ชัดกว่าคนอื่น
- จุดอ่อน: ระวังตัวสูง ไม่ไว้ใจใครง่าย
- จุดแข็ง: วิเคราะห์เร็ว สังเกตเก่ง สติในฝันคม
- ความสัมพันธ์สำคัญ: ภาคิน, รวิ
- Story points ที่มีบทบาท: 9, 10, 18, 19, 23
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: เหยื่อที่คิดว่าตัวเองเสียไปแล้ว -> ผู้ช่วยสืบ -> แกนยุทธวิธีของหน่วย
- น้ำเสียงการพูด: เร็ว คม และมีประชดเบาๆ เมื่อกันตัวเองไว้
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นคนอ่อนหวานง่ายๆ โดยไม่มีการป้องกันตัว

## ตัวละคร: รวิ ศิลาวงศ์
- บทบาทต่อเรื่อง: ally / speed / chaos energy
- Archetype / หน้าที่ในพล็อต: ผู้รอดที่เคยหนีมาตลอด จนเรียนรู้จะย้อนกลับไปช่วยคนอื่น
- อายุ / ภาพลักษณ์: 22 ปี, ไรเดอร์ส่งอาหาร รูปร่างไว คล่อง มอเตอร์ไซค์คืออิสรภาพเดียว
- เป้าหมายภายนอก: ใช้ความเร็วของตนช่วยคนก่อนจะสายเหมือนชีวิตตัวเอง
- ความต้องการภายใน: เลิกหนีความกลัวว่าตนไม่มีค่าถ้าหยุดวิ่ง
- บาดแผล / ปม: เติบโตกับหนี้ครอบครัวและการถูกใช้เวลาเป็นเงินทุกนาที
- ความลับ: เขาเกือบยอมปล่อยตัวเองให้ฝันร้ายกินเพราะเหนื่อยจะสู้
- จุดอ่อน: ใจร้อน ชอบลุยก่อนคิด
- จุดแข็ง: กล้า ตัดสินใจไว อาวุธในฝันตอบสนองเร็ว
- ความสัมพันธ์สำคัญ: ญาดา, ภาคิน
- Story points ที่มีบทบาท: 12, 13, 18, 21-24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: คนที่รอดแบบหนีตลอด -> นักสู้ที่มีทีม -> คนค้ำจังหวะสนามรบ
- น้ำเสียงการพูด: พูดเร็ว หลุดบ่นง่าย มีอารมณ์ขันฝืดๆ
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามนิ่งสุขุมทั้งเรื่องแบบไม่เหลือความหุนหันเดิม

## ตัวละคร: วรันยา เศรษฐสุข
- บทบาทต่อเรื่อง: ally / healer / moral center
- Archetype / หน้าที่ในพล็อต: ผู้รักษาที่เรียนรู้ว่าบางครั้งต้องสู้เพื่อรักษา
- อายุ / ภาพลักษณ์: 29 ปี, พยาบาล ER สีหน้าสงบ มือมั่นคง แต่แบกความล้าหนัก
- เป้าหมายภายนอก: ช่วยพาหะและผู้บาดเจ็บให้กลับมาได้มากที่สุด
- ความต้องการภายใน: ยอมรับว่าตนเองช่วยทุกคนไม่ได้ แต่ยังเลือกช่วยต่อได้
- บาดแผล / ปม: เคยเสียผู้ป่วยเพราะเวรดึกคนไม่พอ จนฝันร้ายใช้ความรู้สึกผิดจู่โจม
- ความลับ: เธอกลัวการหลับ เพราะมักกลับไปเห็นคืนที่ผู้ป่วยตายคามือ
- จุดอ่อน: กดอารมณ์จนเก็บความเจ็บไว้คนเดียว
- จุดแข็ง: มั่นคง เห็นคนอื่นก่อนตัวเอง และใช้อาคมคุ้มครองเก่ง
- ความสัมพันธ์สำคัญ: ภาคิน, ธเนศ
- Story points ที่มีบทบาท: 12, 13, 16, 18, 23
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ผู้รอดที่อยากแค่ไม่ฝัน -> คนรักษาในทีม -> หัวใจของการประคองชีวิตในสนาม
- น้ำเสียงการพูด: สุขุม นุ่ม แต่เด็ดขาดเมื่อต้องตัดสินใจ
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นคนเย็นชาไร้ความสั่นไหว

## ตัวละคร: ธเนศ เกียรติภักดิ์
- บทบาทต่อเรื่อง: ally / shield / anchor
- Archetype / หน้าที่ในพล็อต: คนค้ำแผ่นดินให้ทีมยืนได้
- อายุ / ภาพลักษณ์: 41 ปี, รปภ. กลางคืน ตัวใหญ่ ไหล่กว้าง สีหน้าอ่อนล้าแต่ใจหนักแน่น
- เป้าหมายภายนอก: คุ้มกันคนอื่นไม่ให้ต้องถูกลากเข้าเงามืดเหมือนเขา
- ความต้องการภายใน: เชื่อว่าตัวเองยังปกป้องใครได้ หลังเคยป้องกันครอบครัวไม่สำเร็จ
- บาดแผล / ปม: ภรรยาและลูกจากไปหลังอุบัติเหตุรถ ทำให้เขาอยู่กับคำว่า “ถ้าคืนนั้นข้าตื่นกว่านี้”
- ความลับ: เขาตั้งใจไม่กินยานอนหลับมาหลายปีเพราะกลัวหลับลึกแล้วช่วยใครไม่ได้
- จุดอ่อน: เงียบเกินไปจนคนอื่นเดาใจลำบาก
- จุดแข็ง: อดทนสูง เป็นหลักให้คนอื่น และรับแรงโจมตีได้มาก
- ความสัมพันธ์สำคัญ: วรันยา, ภาคิน
- Story points ที่มีบทบาท: 15, 18, 19, 23-24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: คนที่อยู่กับความผิดของผู้รอด -> โล่ของทีม -> เสาหลักภาคสนามของหน่วย
- น้ำเสียงการพูด: ช้า หนักแน่น ใช้คำน้อยแต่ฟังแล้วเชื่อ
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นลุงตลกกลบความเศร้าเดิม

## ตัวละคร: มอรัส
- บทบาทต่อเรื่อง: antagonist
- Archetype / หน้าที่ในพล็อต: เจ้าแก่นฝันร้ายผู้รวมความสิ้นหวังของคนเมือง
- อายุ / ภาพลักษณ์: ไม่มีรูปแน่นอน มักปรากฏเป็นเงามวลจอแตก สายไฟ และปากจำนวนมาก
- เป้าหมายภายนอก: สร้างมหานครไร้รุ่งและเปิดเมืองให้เป็นแหล่งเพาะพาหะถาวร
- ความต้องการภายใน: ดูดกลืนสติรวมของมนุษย์ให้ทุกคนเชื่อว่าการไม่สู้คือการพัก
- บาดแผล / ปม: ไม่มีแบบมนุษย์ แต่มันก่อตัวจากเศษความเหนื่อย ความละอาย และการถูกมองข้ามของผู้คน
- ความลับ: มันไม่อาจครองร่างที่ยังมีสายสัมพันธ์แน่นแฟ้นกับผู้อื่นได้ง่าย
- จุดอ่อน: เกลียดสติร่วมของผู้รอด เพราะนั่นทำลายรูปทรงที่มันสร้าง
- จุดแข็ง: รู้วิธีใช้ความเหนื่อย ความนอนไม่พอ และความโดดเดี่ยวเป็นอาวุธ
- ความสัมพันธ์สำคัญ: ภาคิน, พาหะหลัก, ทุกผู้รอด
- Story points ที่มีบทบาท: 14-24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: เงาที่ส่งตราดำ -> ผู้คุมมหานครไร้รุ่ง -> แก่นสุดท้ายของไคลแมกซ์
- น้ำเสียงการพูด: เย็น นุ่ม คล้ายปลอบ แต่ทุกคำพาให้ยอมแพ้
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นตัวร้ายพูดเยอะเกินความจำเป็นหรืออธิบายแผนเองยาวๆ
