# Projects

โฟลเดอร์นี้เก็บนิยายแต่ละเรื่องแยกเป็นคนละโปรเจกต์

ตัวอย่าง:
- `sample-project/`
- `my-fantasy-novel/`
- `urban-mystery-01/`

ใช้ `index.md` ในโฟลเดอร์เดียวกันเพื่อดูสถานะรวมของทุกโปรเจกต์

หลักการตั้งชื่อโฟลเดอร์:
- ใช้ slug ภาษาอังกฤษสั้นๆ
- พิมพ์เล็ก
- ใช้ `-` คั่นคำ
- หลีกเลี่ยงช่องว่างและอักขระพิเศษ
