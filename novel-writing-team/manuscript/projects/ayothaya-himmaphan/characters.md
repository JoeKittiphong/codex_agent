# Character Bible

## ตัวละครหลัก

### อินทร์ภพ
- บทบาทต่อเรื่อง: ตัวเอก
- Archetype / หน้าที่ในพล็อต: ศิษย์หนุ่มที่ต้องเติบโตเป็นผู้คุ้มครอง
- อายุ / ภาพลักษณ์: 17 ปี ร่างไม่ใหญ่ ผิวคล้ำแดด ดวงตาไวและมีรอยหมึกยันต์ติดปลายนิ้วเสมอ
- เป้าหมายภายนอก: เอาชีวิตรอดจากป่าหิมพานต์ ช่วยสุพรรณกานต์ และหาทางกลับอโยธยา
- ความต้องการภายใน: เชื่อว่าตนมีคุณค่าเพียงพอแม้ไม่ได้เก่งกาจที่สุด
- บาดแผล / ปม: โตมากับการเป็นศิษย์ที่มักถูกมองว่าจำคาถาได้แต่ลงมือจริงไม่เด็ดขาด
- ความลับ: เขาแอบกลัวว่าหากใช้วิชาผิดพลาดจะทำร้ายคนอื่น จึงลังเลเสมอในยามคับขัน
- จุดอ่อน: ขาดความมั่นใจ ใช้พลังหนักไม่ได้ต่อเนื่อง ชอบคิดว่าตนเป็นภาระ
- จุดแข็ง: ความจำดี สังเกตรายละเอียดเก่ง เมตตา และไม่ทอดทิ้งผู้บาดเจ็บ
- ความสัมพันธ์สำคัญ: สุพรรณกานต์คือคนที่ทำให้เขากล้าข้ามขีดจำกัดของตน อาจารย์พรหมเมศคือเสียงคำสอนในใจ
- Story points ที่มีบทบาท: 1, 3, 5, 7, 13, 16, 18, 21, 23, 24, 27
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ศิษย์หนุ่มไม่มั่นใจ -> ผู้ร่วมชะตากับป่าและนคร -> ชายหนุ่มผู้ใช้วิชาด้วยหัวใจมั่นคง
- น้ำเสียงการพูด: สุภาพ สั้น ตรงไปตรงมา เมื่อกังวลจะเงียบก่อนพูด
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นคนโอหังหรือเก่งแบบไร้ที่มา

### สุพรรณกานต์
- บทบาทต่อเรื่อง: นางเอกและผู้นำทางสู่โลกหิมพานต์
- Archetype / หน้าที่ในพล็อต: รัชทายาทกินรีผู้สูญเสียนครและต้องเลือกระหว่างบ้านเกิดกับชีวิตใหม่
- อายุ / ภาพลักษณ์: รูปโฉมอ่อนวัย ปีกสีทองสลับเขียวมรกต ดวงตาใสเหมือนน้ำลึก
- เป้าหมายภายนอก: ชิงนครเวหาฉิมพลีคืนจากยักษ์และช่วยมารดา
- ความต้องการภายใน: เชื่อว่าตนคู่ควรกับการมีชีวิตที่เลือกได้เอง ไม่ใช่เป็นเพียงธิดาที่ต้องอยู่ในกรอบ
- บาดแผล / ปม: รู้สึกผิดที่หนีออกจากเมืองมาได้ในวันที่คนของตนถูกจับ
- ความลับ: ตั้งแต่แรกนางหวังใช้มนุษย์ที่หลงป่าเป็นกุญแจเปิดผนึกแก้วมยุเรศ แต่ภายหลังรักเขาจริง
- จุดอ่อน: แบกหน้าที่จนไม่ยอมอ่อนแอให้ใครเห็น
- จุดแข็ง: กล้าหาญ ฉลาด รู้จักทางในป่า และมีพลังเพลงเวท
- ความสัมพันธ์สำคัญ: อินทร์ภพคือผู้ทำให้นางเห็นโลกนอกป่าด้วยหัวใจ ไม่ใช่ความกลัว
- Story points ที่มีบทบาท: 6, 7, 8, 10, 17, 19, 23, 24, 25, 26, 27
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: เจ้าหญิงผู้หนีรอด -> ผู้นำที่ยอมรับความช่วยเหลือ -> หญิงผู้เลือกชะตาตนเอง
- น้ำเสียงการพูด: อ่อนหวานแต่มั่นคง ถ้อยคำคล้ายบทเพลงเมื่ออยู่ในอารมณ์สงบ
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นตัวละครที่รอให้ผู้อื่นช่วยอย่างเดียว

### ฤๅษีวชิรญาณ
- บทบาทต่อเรื่อง: ผู้ชี้ทางและคานธีม
- Archetype / หน้าที่ในพล็อต: ครูเงา ผู้คอยย้ำว่าพลังแท้คือใจที่ไม่คด
- อายุ / ภาพลักษณ์: ฤๅษีชราหนวดขาว ผิวราวเปลือกไม้แห้ง ดวงตาคมสงบ
- เป้าหมายภายนอก: รักษาสมดุลป่าหิมพานต์
- ความต้องการภายใน: อยากเห็นผู้ใช้วิชารุ่นใหม่ไม่เดินตามทางทำลายล้าง
- บาดแผล / ปม: เคยเห็นผู้มีเวททำลายป่าด้วยความโลภ
- ความลับ: รู้ตั้งแต่ต้นว่ากวางเผือกนำอินทร์ภพเข้าป่าตามเจตนาของป่า
- จุดอ่อน: ไม่อาจแทรกแซงชะตาโดยตรง
- จุดแข็ง: มองคนขาด รู้กฎเก่าของป่า
- ความสัมพันธ์สำคัญ: เป็นกระจกสะท้อนให้อินทร์ภพเห็นศักยภาพในตัวเอง
- Story points ที่มีบทบาท: 9, 15, 18
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ผู้เฝ้ามอง -> ผู้ชี้ทาง -> ผู้ส่งศิษย์คืนโลกมนุษย์
- น้ำเสียงการพูด: ช้า หนักแน่น คล้ายท่องคาถา
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามเฉลยหรือช่วยง่ายเกินไป

### ท้าวกัณฐ์เพลิง
- บทบาทต่อเรื่อง: ตัวร้ายหลัก
- Archetype / หน้าที่ในพล็อต: ผู้ปกครองด้วยกำลังและความหวาดกลัว
- อายุ / ภาพลักษณ์: ร่างยักษ์สีหม่น ดวงตาแดงเหมือนถ่านคุกรุ่น ถือกระบองเหล็กไฟ
- เป้าหมายภายนอก: ครอบครองเวหาฉิมพลีและใช้แก้วมยุเรศขยายอำนาจสู่โลกมนุษย์
- ความต้องการภายใน: อยากพิสูจน์ว่ากำลังคือกฎอันแท้จริงของทุกโลก
- บาดแผล / ปม: ถูกดูแคลนจากยักษ์เผ่าใหญ่กว่าในอดีต
- ความลับ: เขาไม่อาจใช้แก้วมยุเรศเต็มพลัง เพราะเจตนาเต็มไปด้วยความครอบครอง
- จุดอ่อน: มองความเมตตาเป็นความอ่อนแอ จึงอ่านพลังของใจผิดเสมอ
- จุดแข็ง: กำลังมหาศาล กองทัพมาก และรู้วิธีใช้ความกลัวควบคุมเมือง
- ความสัมพันธ์สำคัญ: สุพรรณกานต์คือสัญลักษณ์ของสิ่งที่เขาควบคุมไม่ได้ อินทร์ภพคือความน่าขันที่กลายเป็นภัยจริง
- Story points ที่มีบทบาท: 12, 14, 21, 22, 24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ผู้ยึดครองมั่นใจ -> ผู้ล่าแก้วมยุเรศ -> ผู้พ่ายแพ้แก่พลังที่ตนดูแคลน
- น้ำเสียงการพูด: ต่ำ หนัก ชอบเยาะหยัน
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นตัวร้ายตื้นเขินไร้เหตุผลด้านอำนาจ
