# Continuity Tracker

## Timeline
- ตอน 1: อินทร์ภพใช้ชีวิตในสำนักอาคมแห่งอโยธยาและถูกปักธีมเรื่องอาคมกับเมตตา
- ตอน 2: เข้าสอบภาคสนาม เห็นกวางเผือก และหลงผ่านม่านหมอกสู่ป่าหิมพานต์
- ตอน 3: เอาตัวรอดคืนแรกในป่าหิมพานต์ ท่ามกลางสัตว์ลวงและอันตราย
- ตอน 4: ช่วยสุพรรณกานต์หนีทหารยักษ์ และรู้ว่านางเป็นนครธิดาแห่งเวหาฉิมพลี
- ตอน 5: ทั้งสองร่วมเดินทาง เรียนรู้กฎของป่า และเริ่มไว้ใจกัน
- ตอน 6: เข้าค่ายลี้ภัยกินรี เห็นบาดแผลของสงคราม และพบภัยใหม่คืบเข้าค่าย
- ตอน 7: อินทร์ภพช่วยค่ายจากเถาวัลย์อสูร ได้รับการยอมรับครั้งแรก
- ตอน 8: ฤๅษีวชิรญาณอธิบายเรื่องแก้วมยุเรศและทางกลับโลกมนุษย์
- ตอน 9: เดินทางสู่ถ้ำบุษบก ผ่านหุบเมฆและแม่น้ำที่ไหลย้อนฟ้า
- ตอน 10: ผ่านบททดสอบของผู้พิทักษ์เขี้ยวแก้ว
- ตอน 11: พบความลับเก่าแก่ของเมืองและผนึกในถ้ำบุษบก
- ตอน 12: อินทร์ภพเปิดผนึกเลือด รับแก้วมยุเรศ และหนีออกจากถ้ำ
- ตอน 13: กลับถึงค่ายลี้ภัยแล้วพบว่าค่ายถูกยักษ์บุกเผา
- ตอน 14: ซ่อนตัวที่สระจันทร์มยุราและรักษาแผล พร้อมความจริงใจที่เปิดมากขึ้น
- ตอน 15: รู้ความจริงว่าแก้วจะไม่เปิดทางให้ผู้หนีจากหน้าที่
- ตอน 16: อินทร์ภพผ่านจุดต่ำสุดทางใจ และแก้วชี้ทางลับสู่เวหาฉิมพลี
- ตอน 17: รวบรวมผู้รอดและพันธมิตรใหม่จากลิงหิมพานต์ นักพรต และกินรีกระจัดกระจาย
- ตอน 18: ฝ่าทางลับใต้ผาเมฆและเห็นเวหาฉิมพลีครั้งแรก
- ตอน 19: สำรวจเมืองฟ้าที่ถูกล่ามและรู้ว่าพระนางฉิมพลีเทวียังมีชีวิต
- ตอน 20: ลอบช่วยเชลยชุดแรกและได้ข้อมูลโพรงลมสู่หอแก้ว
- ตอน 21: สุพรรณกานต์กลับสู่เรือนดนตรีและพบเครื่องหมายลับจากมารดา
- ตอน 22: อินทร์ภพเรียนรู้อาคมคุ้มครองในฐานะพลังที่เกิดจากผู้คนร่วมกัน
- ตอน 23: คืนก่อนศึกใหญ่ ทั้งสองเผยความรู้สึกลึกขึ้นและแจกแผนการตีคืน
- ตอน 24: อินทร์ภพลอบเข้าสู่หอแก้วชั้นล่างผ่านโพรงลม
- ตอน 25: ปลดโซ่อาคมและทำให้ระฆังนครดังขึ้นอีกครั้ง
- ตอน 26: ศึกทั่วเมืองเปิดฉาก และท้าวกัณฐ์เพลิงปรากฏที่หอแก้ว
- ตอน 27: อินทร์ภพเผชิญหน้าท้าวกัณฐ์เพลิงและเปิดเขตอาคมได้เพียงครึ่งเดียว
- ตอน 28: สุพรรณกานต์ช่วยพระนางฉิมพลีเทวีออกจากวังชั้นใน ขณะลานแก้วใกล้แตก
- ตอน 29: อินทร์ภพเปลี่ยนจากอาคมโจมตีเป็นอาคมคุ้มครอง เมืองจึงเริ่มตอบรับเต็มที่
- ตอน 30: สุพรรณกานต์ผสานเสียงเพลงกับอินทร์ภพจนท้าวกัณฐ์เพลิงเริ่มพ่าย
- ตอน 31: ปีกแห่งแสงครอบทั้งนคร ยักษ์พังทลาย และเวหาฉิมพลีเป็นอิสระ
- ตอน 32: เมืองเก็บศพ เยียวยาผู้รอด และเริ่มหายใจอีกครั้งหลังชัยชนะ
- ตอน 33: พระนางฉิมพลีเทวีคืนสิทธิ์เลือกแก่ธิดา และสุพรรณกานต์ตัดสินใจไปอโยธยา
- ตอน 34: ที่สระจันทร์มยุรา สุพรรณกานต์แปลงกายเป็นมนุษย์และลาป่าหิมพานต์
- ตอน 35: ทั้งคู่กลับสู่อโยธยา พบอาจารย์พรหมเมศ และเริ่มใช้ชีวิตใหม่
- ตอน 36: ชีวิตใหม่ในเรือนมนุษย์เริ่มต้น โดยป่าหิมพานต์ยังคงอยู่ในหัวใจทั้งคู่

## Character State
- อินทร์ภพ:
  - สถานะล่าสุด: เติบโตจากศิษย์ปลายแถวเป็นผู้ใช้อาคมคุ้มครองที่เข้าใจคุณค่าของวิชาตนเอง
  - บาดแผล/ร่องรอย: ผ่านการใช้เวทเกินกำลัง มีรอยไหม้และรอยแผลจากศึก แต่รอดกลับมา
  - อารมณ์คงค้าง: คิดถึงผู้สูญเสียเสมอ แต่มีความสงบและมั่นคงกว่าตอนต้นเรื่อง
  - จุดเปลี่ยนสำคัญ: ยอมรับว่าความกลัวไม่ใช่ความอ่อนแอ หากใช้มันเพื่อปกป้องผู้อื่น
- สุพรรณกานต์:
  - สถานะล่าสุด: ชิงเมืองคืนสำเร็จ เลือกแปลงกายเป็นมนุษย์และไปอโยธยา
  - บาดแผล/ร่องรอย: ปีกเดิมละลายเป็นแสงในพิธีแปลงกาย เก็บตัวตนเดิมไว้ในความทรงจำ
  - อารมณ์คงค้าง: อาลัยบ้านเกิด แต่มิได้เสียใจที่เลือกชีวิตใหม่
  - จุดเปลี่ยนสำคัญ: จากนครธิดาผู้หนี กลายเป็นหญิงสาวที่เลือกชะตาตนเองได้
- พระนางฉิมพลีเทวี:
  - สถานะล่าสุด: กลับคืนสู่บัลลังก์และฟื้นนครเวหาฉิมพลี
- ฤๅษีวชิรญาณ:
  - สถานะล่าสุด: ยังเป็นผู้เฝ้าป่าและผู้รู้ว่าป่าเลือกอินทร์ภพตั้งแต่ต้น
- ครามเดช / รจนา / อักษรเทพ / ลิงหิมพานต์:
  - สถานะล่าสุด: ผู้ช่วยสำคัญในการชิงนครคืนและการฟื้นเมืองหลังศึก

## Relationship State
- อินทร์ภพ / สุพรรณกานต์:
  - สถานะปัจจุบัน: คู่ร่วมชะตาที่เลือกใช้ชีวิตเคียงกันในโลกมนุษย์
  - เปลี่ยนจากอะไร: คนแปลกหน้าร่วมหนี -> พันธมิตร -> คนสำคัญของกันและกัน
- อินทร์ภพ / สำนักอาคม:
  - สถานะปัจจุบัน: กลับคืนสำนักในฐานะคนใหม่ที่ผ่านบททดสอบจริงจากโลกภายนอก
- สุพรรณกานต์ / เวหาฉิมพลี:
  - สถานะปัจจุบัน: มิได้ตัดขาดจากบ้านเกิด แต่เปลี่ยนจากผู้ถูกผูกไว้กับหน้าที่ เป็นผู้ที่เลือกกลับมาได้ด้วยใจ

## Object / Clue Tracker
- กวางเผือก:
  - ปรากฏครั้งแรก: ตอน 2
  - บทสรุป: เป็นสัญญาณว่าป่าหิมพานต์เลือกอินทร์ภพเข้าสู่ชะตานี้
- แก้วมยุเรศ:
  - ปรากฏชัดครั้งแรก: ตอน 12
  - ตอนนี้อยู่ที่ใคร: ใช้คืนบทบาทสู่เวหาฉิมพลีหลังชิงนครสำเร็จ
  - หน้าที่ต่อพล็อต: เป็นทั้งกุญแจกลับโลกมนุษย์ หัวใจอาคมของเมือง และเครื่องพิสูจน์เจตนาผู้ถือ
  - บทสรุป: ตอบรับอินทร์ภพเมื่อเขาใช้อำนาจเพื่อคุ้มครอง มิใช่ครอบครอง
- คาถาคุ้มภัย / อาคมคุ้มครอง:
  - ปรากฏครั้งแรก: ตอน 1-2
  - บทสรุป: กลายเป็นธีมและอาวุธหลักในไคลแมกซ์
- ปิ่นปีกทองของพระนางฉิมพลีเทวี:
  - ปรากฏชัดครั้งแรก: ตอน 21
  - บทสรุป: เป็นเครื่องหมายจากมารดาที่ชี้ทางให้สุพรรณกานต์กลับบ้านอย่างถูกต้อง
