# Character Bible

## ตัวละครหลัก

### ภูริ
- บทบาทต่อเรื่อง: ตัวเอก
- Archetype / หน้าที่ในพล็อต: ผู้รอดชีวิตที่ต้องเรียนรู้ความรับผิดชอบร่วม
- อายุ / ภาพลักษณ์: 27 ปี ผอมสูง มือมีรอยไหม้จากงานช่าง
- เป้าหมายภายนอก: ช่วยมินและเปิดโปงโครงการลับ
- ความต้องการภายใน: เลิกเชื่อว่าตนควรอยู่คนเดียวเพื่อไม่ให้ใครเดือดร้อน
- บาดแผล / ปม: เคยทำงานซ่อมระบบให้รัฐจนมีคนตายจากความผิดพลาดที่เขาไม่กล้ายอมรับ
- ความลับ: เขาเคยเซ็นรับรองระบบย่อยที่นำไปสู่โครงการฟ้าศพ
- จุดอ่อน: ไม่ไว้ใจใคร ชอบแบกคนเดียว
- จุดแข็ง: อ่านระบบเก่ง ตัดสินใจเร็วภายใต้แรงกดดัน
- ความสัมพันธ์สำคัญ: มินคือเหตุผลที่ทำให้เขาเคลื่อนไหว เมษาคือคนที่ค่อยๆ บังคับให้เขาเชื่อใจผู้อื่น
- Story points ที่มีบทบาท: 1, 3, 5, 7, 13, 17, 18, 24, 26, 27
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: เอาตัวรอดคนเดียว -> แตกสลายเพราะพยายามแบกทุกอย่าง -> เลือกร่วมมือและรับผิดชอบต่อคนอื่น
- น้ำเสียงการพูด: สั้น ตรง แห้ง แต่เวลาอารมณ์แตกจะเงียบมากกว่าตะโกน
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามพูดสวยหรูหรืออธิบายตัวเองมากเกินจำเป็น

### มิน
- บทบาทต่อเรื่อง: น้องสาวและแกนศีลธรรมของเรื่อง
- Archetype / หน้าที่ในพล็อต: ผู้หายตัวที่ยังคงมีอิทธิพลต่อทุกการตัดสินใจ
- อายุ / ภาพลักษณ์: 20 ปี ตาไวและยิ้มง่าย
- เป้าหมายภายนอก: เปิดโปงความจริงแม้ต้องแลกด้วยตัวเอง
- ความต้องการภายใน: อยากให้พี่ชายเลิกใช้ชีวิตแบบหลบโลก
- บาดแผล / ปม: เติบโตมากับการเห็นคนชั้นล่างถูกใช้แล้วถูกลืม
- ความลับ: เธอยอมเข้าโครงการบางส่วนเพื่อเข้าถึงแกนข้อมูลจากข้างใน
- จุดอ่อน: ยอมเสี่ยงตัวเองมากเกินไป
- จุดแข็ง: กล้าหาญ มองไกล และมักเลือกเพื่อคนอื่น
- ความสัมพันธ์สำคัญ: ภูริ, เมษา
- Story points ที่มีบทบาท: 5, 13, 15, 20, 22, 24, 27
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ผู้ส่งสัญญาณ -> หัวใจของปัญหา -> ผู้รอดชีวิตที่เห็นเมืองเปลี่ยน
- น้ำเสียงการพูด: เร็ว ฉลาด อ่อนโยนแต่เด็ดขาด
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามอ่อนแอแบบไร้เหตุผลเพื่อดันดราม่า

### เมษา
- บทบาทต่อเรื่อง: พันธมิตรหลักและ foil ของภูริ
- Archetype / หน้าที่ในพล็อต: คนที่เชื่อว่าระบบต้องถูกเปิดโปง ไม่ว่าจะราคาเท่าไร
- อายุ / ภาพลักษณ์: 29 ปี แต่งตัวคล่องตัว สายตาคม
- เป้าหมายภายนอก: ทำลายโครงการฟ้าศพและเผยข้อมูลสู่สาธารณะ
- ความต้องการภายใน: พิสูจน์ว่าการสูญเสียพี่ชายของเธอมีความหมาย
- บาดแผล / ปม: พี่ชายตายจากการทดลองรุ่นก่อน
- ความลับ: เธอเคยคิดใช้มินเป็นหลักฐานมากกว่าจะช่วยเธอ
- จุดอ่อน: มองคนเป็นเครื่องมือเมื่อเร่งรีบ
- จุดแข็ง: วิเคราะห์เย็น กล้าเสี่ยง ประสานเครือข่ายเก่ง
- ความสัมพันธ์สำคัญ: ปะทะแต่ค่อยๆ เชื่อใจกับภูริ
- Story points ที่มีบทบาท: 7, 9, 12, 19, 23, 24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: นักสู้หัวแข็ง -> คนที่เริ่มเห็นค่าของชีวิตรายคน -> พันธมิตรที่ยอมเสี่ยงเพื่อช่วยทั้งคนและเมือง
- น้ำเสียงการพูด: ชัด คม ไม่เสียเวลา
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นตัวช่วยไร้ความเห็นของตัวเอง

## ตัวละครรอง

### ผู้อำนวยการอคิน
- บทบาทต่อเรื่อง: ตัวร้ายหลัก
- ความสัมพันธ์กับตัวละครหลัก: มองภูริเป็นช่างคนหนึ่งที่ไม่เข้าใจราคาของความอยู่รอด
- หน้าที่ต่อพล็อต: เสนอเหตุผลของระบบที่ยอมเสียสละคนส่วนน้อยเพื่อรักษาเมือง
