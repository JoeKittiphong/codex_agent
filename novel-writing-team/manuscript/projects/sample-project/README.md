# Sample Project: ฝนสุดท้ายเหนือเมืองแก้ว

ตัวอย่างนี้สาธิต workflow ตั้งแต่ synopsis ไปจนถึง episode files

โทน: ดิสโทเปีย / ลึกลับ / ดราม่า
จำนวนตอนตัวอย่าง: 4 ตอน
POV: บุคคลที่สามจำกัดมุมมองที่ภูริ

ไฟล์ในชุดนี้เป็นตัวอย่างการกรอกโครงให้ครบทั้งระบบ และมี episode sample สำหรับดูรูปแบบการเขียนจริง
