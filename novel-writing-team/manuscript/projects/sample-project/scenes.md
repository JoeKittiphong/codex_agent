# Scene Plan

## Scene S01
- Episode: 1
- Point Mapping: Point 1 / Point 2 / Point 3
- Sequence Mapping: Sequence 1
- Act: 1
- POV: ภูริ
- สถานที่และเวลา: เขตชั้นล่าง ตอนเย็น
- ตัวละครในฉาก: ภูริ, คนงานในชุมชน
- ใครทำอะไร ที่ไหน อย่างไร: ภูริซ่อมเครื่องดักไอน้ำให้ชุมชนท่ามกลางข่าวลือเรื่องคนหาย
- เป้าหมายของฉาก: เปิดโลกและตัวเอก
- ความขัดแย้ง: ระบบขัดข้อง คนเริ่มตื่นกลัว แต่ภูริไม่อยากยุ่งเกินงาน
- Turning beat: เขาเห็นสัญลักษณ์ลับที่มินชอบใช้ถูกขีดไว้บนแผงเครื่อง
- การเปลี่ยนอารมณ์: จากกิจวัตรสู่ความกังวล
- ข้อมูลใหม่ที่ได้: มินอาจทิ้งรอยไว้ให้เขา
- ผลลัพธ์ปลายฉาก: ภูริเริ่มตามรอย
- Hook ท้ายฉาก: มีข้อความเข้ารหัสส่งเข้าวิทยุเก่าของเขา
- ความยาวเป้าหมาย: 900 คำ
