# Continuity Tracker

## Timeline
- วัน/เวลา: ตอนที่ 1 ช่วงเย็นถึงกลางคืน
- เกิดอะไรขึ้น: ภูริพบสัญลักษณ์ของมิน ได้ข้อความลับ และหนีออกจากห้องกับเมษา
- อยู่ในตอน: ep-01-signal-under-glass.md

## Character State
- ตัวละคร: ภูริ
- สถานะล่าสุด: เริ่มออกจากชีวิตเดิมและยอมร่วมมือกับเมษา
- บาดแผล/ร่องรอย: ยังไม่มีบาดแผลหนัก แต่ร่างกายอ่อนล้าจากงานช่างและการหนี
- อารมณ์คงค้าง: กังวล ไม่ไว้ใจ แต่เริ่มมีความหวัง
- ความลับที่รู้: มินเกี่ยวข้องกับโครงการฟ้าศพ
- สิ่งที่ยังไม่รู้: มินอยู่ที่ไหน สภาพเป็นอย่างไร และเมษาไว้ใจได้แค่ไหน
- คำสัญญาหรือภาระที่แบกอยู่: ต้องตามหามินและหาความจริงของไฟล์

## Relationship State
- คู่ความสัมพันธ์: ภูริ / เมษา
- สถานะปัจจุบัน: พันธมิตรจำเป็นที่ยังไม่ไว้ใจกัน
- เปลี่ยนจากอะไร: คนแปลกหน้า -> คนที่ต้องหนีไปด้วยกัน
- ต้องระวังอะไรในตอนถัดไป: อย่าให้สนิทกันเร็วเกินไป

## Object / Clue Tracker
- วัตถุหรือเบาะแส: เมมโมรีของมิน
- ปรากฏครั้งแรก: ตอน 1
- ตอนนี้อยู่ที่ใคร: ภูริ
- หน้าที่ต่อพล็อต: พาเข้าสู่โครงการฟ้าศพ
- ต้องจ่ายคืนเมื่อไร: ตอน 2 เมื่อใช้เปิดเส้นทางสู่คลังข้อมูล

## Open Loops
- คำถามที่ยังไม่คลี่คลาย: มินยังมีชีวิตหรือไม่
- เปิดไว้ตั้งแต่ตอน: 1
- ควรกลับมาจ่ายคืนประมาณตอนไหน: ตอน 2 ปลายตอน
