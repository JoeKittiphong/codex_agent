# Character Bible

## ตัวละครหลัก

### ศิลา
- บทบาทต่อเรื่อง: ตัวเอก
- Archetype / หน้าที่ในพล็อต: นักวางแผนอ่อนแอที่ถูกบังคับให้กลายเป็นนักสู้ผู้สร้างพลังเอง
- อายุ / ภาพลักษณ์: 22 ปี ผอม เอวบาง ไหล่ไม่กว้าง ผิวมีรอยไหม้ไฟจางๆ ตามนิ้วและข้อมือจากงานซ่อมวงจร ดวงตาดำไวเหมือนคนคำนวณตลอดเวลา
- ภาพจำแรกตอนเปิดตัว: เด็กหนุ่มในตรอกสลัมที่ใช้มีดสั้นเรืองไฟตัดสายเคเบิลกลางฝนด้วยมือสั่นนิดๆ แต่สายตาไม่พลาดเลยสักจุด
- ภาพลักษณ์ที่คนอื่นเข้าใจ: เด็กช่างหัวดี ปากไว เอาตัวรอดเก่ง แต่บู๊ไม่ไหว
- ตัวตนจริงลึกลงไป: คนที่กลัวการสูญเสียจนพยายามวางแผนแทนความไว้ใจทุกอย่าง
- แกนตัวตน / ความขัดแย้งในตัวเอง: อยากปกป้องรินด้วยทุกวิถีทาง แต่เชื่อว่าร่างกายอันอ่อนแอทำให้ตนไม่มีสิทธิพลาดหรือเสี่ยงแบบคนอื่น
- เป้าหมายภายนอก: เอาน้ำอมฤทธิ์มารักษาริน และหยุดนาคาสีชาดไม่ให้ใช้มันสร้างกองทัพฤทธิ์เทียม
- ความต้องการภายใน: ยอมรับว่าความแข็งแกร่งที่แท้ไม่ได้มีแค่การคุมสถานการณ์ แต่มาจากการยอมแบกรับราคาเพื่อคนอื่น
- ความกลัวหลัก: ตัดสินใจพลาดจนทำให้รินตายต่อหน้า หรือกลายเป็นแค่คนฉลาดที่ปกป้องใครไม่ได้จริง
- ความเชื่อผิดพลาด: ถ้าลดความเสี่ยงได้มากพอ ก็ไม่จำเป็นต้องแข็งแรงจริง
- บาดแผล / ปม: โตมากับพ่อที่หายตัว รินที่ต้องออกล่าแทน และสลัมที่สอนว่าคนแพ้มักตายเพราะกล้าช้าไปก้าวหนึ่ง
- กลไกป้องกันตัว: วิเคราะห์แทนอารมณ์ พูดเร็วเมื่อเครียด ชอบหาทางหนีสำรองก่อนคุยจริงเสมอ
- ความลับ: ลึกๆ เขาอิจฉารินและพรานคนอื่นที่กล้าลงมือด้วยร่างกายตัวเองได้ ส่วนเขาต้องใช้เล่ห์ทุกครั้ง
- จุดอ่อน: ร่างกายเหนื่อยง่าย ปวดศีรษะเมื่อใช้ไฟเกินพิกัด และชอบพยายามควบคุมทุกคนเมื่อกลัว
- จุดแข็ง: อ่านเส้นทางไว คิดเชิงระบบเร็ว ดัดแปลงเครื่องมือเก่ง และมีสัญชาตญาณรับจังหวะอันตรายเมื่อถูกต้อนจนมุม
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่ทิ้งผู้บริสุทธิ์เป็นเหยื่อ ไม่ยอมขายคนใกล้ตัวเพื่อรอด และยอมเจ็บเองมากกว่าจะให้รินถูกใช้ซ้ำ
- จุดเปราะบาง / trigger: เสียงรินไอ เลือดที่ปนเศษแก้วดำ เด็กหรือคนอ่อนแอที่ถูกเอาไปเป็นวัตถุดิบ
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ใช้ข้อมูล จังหวะ และสภาพแวดล้อมก่อนใช้กำลังตรง
- ภาษากายหรือพฤติกรรมติดตัว: เคาะนิ้วกับของแข็งเวลาคิด ชอบเหลือบมองแหล่งไฟใกล้ตัว และเม้มปากเมื่อจำใจขอความช่วยเหลือ
- ความสัมพันธ์สำคัญ:
  - ริน: พี่สาว คนสำคัญที่สุด และบาดแผลที่เดินหายใจอยู่
  - พรานอิน: ครูแบบขัดตา ผู้บังคับให้เขายอมรับความจริงของป่าและตัวเอง
  - ไหม: เพื่อนจากสลัมที่ทำให้เห็นมุมของคนธรรมดาในเมือง
  - พรานเมฆ: ภาพอนาคตของคนที่ใช้พลังเพื่อควบคุมทุกอย่าง
- Story points ที่มีบทบาท: 1-27 แทบทั้งหมด
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: นักเอาตัวรอดที่ซ่อนหลังแผน -> ผู้เรียนรู้ราคาของพลังและความจริง -> พรานทมิฬผู้ใช้สมองและหัวใจพร้อมกัน
- Dialogue Fingerprint:
  - ระดับภาษา: ร่วมสมัยตรงๆ ออกกวนบางจังหวะ
  - จังหวะประโยค: สั้น เร็ว มีการหักกลางประโยคเมื่อคิดทัน
  - คำที่ชอบใช้: “เดี๋ยวก่อน” “ไม่คุ้ม” “เอาตามนี้”
  - คำที่ไม่ใช้ / คำที่เลี่ยง: เลี่ยงคำหวาน เลี่ยงคำสาบานลอยๆ
  - ระดับความตรง: ตรงกับข้อเท็จจริง แต่หลบความรู้สึก
  - วิธีใช้อารมณ์ขันหรือประชด: ประชดแห้งๆ เพื่อกันตัวเองไม่ให้ตื่น
  - เวลาถูกกดดันจะพูดอย่างไร: เร็วขึ้น สั้นขึ้น และออกคำสั่งเป็นขั้นตอน
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: อ้อมนิดเดียวก่อนยอมรับสั้นๆ
- ตัวอย่างบทพูด:
  - ปกติ: “ถ้ามีเวลาพังของ ก็ต้องมีเวลาให้ผมคิดทางซ่อมด้วย”
  - ตอนกดดัน: “อิน ถอยขวาอีกสองก้าว เดี๋ยวนี้ ถ้าพลาดผมชาร์จให้ไม่ทัน”
  - ตอนเปราะบาง: “ผมไม่ได้กลัวตายหรอก ผมกลัวตายแล้วยังช่วยพี่ไม่ได้ต่างหาก”
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นพระเอกพูดยาวเชิงเทศนา หรือเก่งรอบด้านแบบไร้ต้นทุน

### ริน
- บทบาทต่อเรื่อง: พี่สาวผู้เป็นหัวใจของภารกิจ และอดีตพรานทมิฬผู้สะท้อนสิ่งที่ศิลาอยากเป็นและกลัวจะสูญเสีย
- Archetype / หน้าที่ในพล็อต: แรงขับส่วนตัวของเรื่อง + เงาอดีตของวงการพราน
- อายุ / ภาพลักษณ์: 28 ปี ผอมจากโรค แต่ยังเห็นเค้าโครงของคนที่เคยเร็วและแข็งแรง ผิวมีรอยผลึกแก้วดำกินจากไหล่ลงแขนซ้าย และแผ่ความร้อนเป็นระยะ
- ภาพจำแรกตอนเปิดตัว: หญิงสาวผมยาวรุงรังนั่งอยู่ข้างหน้าต่างเหล็ก ท่ามกลางแสงนีออนป่วยๆ โดยใช้ผ้าพันแขนที่แตกร้าวเหมือนซ่อนถ่านไฟไว้ใต้ผิว
- ภาพลักษณ์ที่คนอื่นเข้าใจ: คนป่วยใกล้ตายที่ต้องให้ดูแล
- ตัวตนจริงลึกลงไป: อดีตพรานที่เคยตัดสินใจเร็วและใช้ร่างกายปกป้องคนอื่นจนตัวเองพัง
- แกนตัวตน / ความขัดแย้งในตัวเอง: อยากให้ศิลารอดจากเส้นทางพราน แต่รู้ว่าความลับที่ปิดไว้กำลังฆ่าโอกาสเดียวของตัวเอง
- เป้าหมายภายนอก: รักษาศิลาไม่ให้เดินซ้ำเส้นทางอันตรายของตน แม้ปลายทางคือการตายของตัวเอง
- ความต้องการภายใน: ยอมรับว่าตนไม่อาจแบกความผิดและการปกป้องน้องไว้คนเดียวอีกต่อไป
- ความกลัวหลัก: ศิลาจะตายเพราะเธอ หรือกลายเป็นคนแข็งกระด้างเพราะต้องเสียเธอไป
- ความเชื่อผิดพลาด: ถ้าปิดความจริงไว้ ศิลาจะปลอดภัยกว่า
- บาดแผล / ปม: เคยใช้ไฟหยิบยืมเกินขีดระหว่างงานล่าครั้งใหญ่จนเป็นโรคอาคมย้อนกลับ และสูญเสียพ่อไปกับการตามหาน้ำอมฤทธิ์
- กลไกป้องกันตัว: ทำเป็นแข็ง พูดแรงเพื่อผลักคนออก และพยายามลุกทำเองแม้ร่างไม่ไหว
- ความลับ: เธอเคยเห็นบันทึกชิ้นหนึ่งของพ่อที่เตือนว่าน้ำอมฤทธิ์ไม่ใช่พรอย่างเดียว จึงยื้อไม่บอกศิลามานาน
- จุดอ่อน: โรคทรุดฉับพลัน แผลไฟย้อนทำให้เจ็บจนควบคุมสติไม่ได้บางช่วง
- จุดแข็ง: ประสบการณ์พราน การอ่านคน การสอนเอาตัวรอด และความใจแข็งเมื่อถึงคราวต้องตัดสินใจ
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่ยอมใช้คนอ่อนแอเป็นบันได ไม่ยอมให้ศิลาแลกชีวิตแบบไร้ค่า
- จุดเปราะบาง / trigger: กลิ่นไหม้จากอาคมย้อนกลับ เสียงโลหะจากอุปกรณ์ล่าของพ่อ และเวลาศิลาพูดเหมือนไม่ต้องการใคร
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ข่มด้วยน้ำเสียงนิ่งและประสบการณ์ ไม่ใช่เสียงดัง
- ภาษากายหรือพฤติกรรมติดตัว: ชอบจับข้อมือซ้ายตอนเจ็บ ซ่อนอาการไอด้วยการหันหน้าเข้ากำแพง และยังจัดมีดให้หันคมออกจากตัวเสมอ
- ความสัมพันธ์สำคัญ:
  - ศิลา: น้องชายที่เธอเลี้ยงแทบเป็นลูก
  - พ่อ: ความทรงจำที่เธอทั้งรักทั้งโทษ
  - พรานอิน: คนรุ่นเดียวกันในสนามล่าเก่าที่รู้เรื่องพรานทมิฬของเธอ
- Story points ที่มีบทบาท: 3, 5, 6, 16, 21, 25, 26
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: คนป่วยที่ปิดความจริง -> ผู้ถูกจับเป็นเดิมพัน -> ผู้รอดที่เห็นศิลาเติบโตเกินความกลัวของตน
- Dialogue Fingerprint:
  - ระดับภาษา: ตรง แข็ง แต่มีความเอ็นดูแทรกเวลาเผลอ
  - จังหวะประโยค: ชัด ไม่ฟุ่มเฟือย เหมือนคนคุ้นสนาม
  - คำที่ชอบใช้: “ฟังให้จบ” “อย่าฝืนโง่ๆ” “ฉันเคยเห็นมาแล้ว”
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่อ้อน ไม่คร่ำครวญ
  - ระดับความตรง: สูงมาก โดยเฉพาะเวลาห่วง
  - วิธีใช้อารมณ์ขันหรือประชด: ประชดแรงแบบพี่สาว
  - เวลาถูกกดดันจะพูดอย่างไร: ยิ่งนิ่ง ยิ่งคม
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: มักยอมรับโดยไม่ใส่น้ำตาล
- ตัวอย่างบทพูด:
  - ปกติ: “มีดเอาไว้รอด ไม่ได้เอาไว้โชว์ว่าใจถึง”
  - ตอนกดดัน: “ศิลา ถ้าจะหนี ก็หนีอย่างคนคิด ถ้าจะสู้ ก็สู้ให้จบ อย่าค้างกลางทาง”
  - ตอนเปราะบาง: “ฉันไม่ได้กลัวตาย ฉันกลัวนายอยู่ต่อโดยคิดว่าตัวเองมาช้าไปตลอดชีวิต”
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามทำให้เธอเป็นแค่คนป่วยน่าสงสารไร้ความสามารถหรือไร้แรงต้านในใจ

### พรานอิน
- บทบาทต่อเรื่อง: เมนเทอร์ พรานรุ่นใหญ่ และตัวแทนของความแข็งแกร่งแบบเก่า
- Archetype / หน้าที่ในพล็อต: ครูปากร้ายที่พาพระเอกผ่านโลกป่าและท้าทายวิธีคิดเดิม
- อายุ / ภาพลักษณ์: ราว 46 ปี ตัวหนา ผิวกร้าน แผลเป็นตัดผ่านคาง ขาขวาใส่อุปกรณ์ค้ำโลหะเก่าแต่ยังเดินป่าเร็วผิดคนเจ็บ
- ภาพจำแรกตอนเปิดตัว: ชายแก่เครารุงรังที่ดื่มเหล้าข้าวจากขวดโลหะและหัวเราะใส่เจ้าหน้าที่นาคาสีชาดราวกับไม่มีใครยิงเขาตายได้
- ภาพลักษณ์ที่คนอื่นเข้าใจ: พรานตกยุค ปากเสีย ชอบหาเรื่อง
- ตัวตนจริงลึกลงไป: คนที่เสียคนในทีมเก่าให้การโลภของนาคาสีชาดและยังไม่เคยให้อภัยตัวเอง
- แกนตัวตน / ความขัดแย้งในตัวเอง: เชื่อในการเอาตัวรอดแบบพรานล้วนๆ แต่เห็นศักยภาพใหม่ในศิลาและลังเลว่าจะผลักเด็กคนนี้เข้าสนามทำไม
- เป้าหมายภายนอก: เข้าใกล้นาคาสีชาดพอจะหาหลักฐานและจ่ายหนี้เลือดเก่า
- ความต้องการภายใน: ยอมให้ตัวเองเชื่อใจใครอีกครั้ง และส่งวิชาที่มีให้คนรุ่นใหม่อย่างไม่หลบ
- ความกลัวหลัก: เด็กที่ตนช่วยไว้จะตายเพราะเชื่อเขา
- ความเชื่อผิดพลาด: คนอ่อนแอเหมือนศิลาไม่มีวันอยู่ในป่าได้นานพอ
- บาดแผล / ปม: ทีมเดิมถูกนาคาสีชาดใช้เป็นเหยื่อล่อจนตายเกือบหมด เขารอดโดยเสียขาและศรัทธา
- กลไกป้องกันตัว: พูดหยาบ พูดเย้ย และทดสอบคนก่อนยอมรับ
- ความลับ: เขาเคยเห็นพ่อของศิลาในป่าครั้งสุดท้าย แต่ไม่แน่ใจว่าชายคนนั้นตั้งใจหายไปหรือถูกลากเข้าแกนเรื่องน้ำอมฤทธิ์
- จุดอ่อน: บาดแผลเก่าทำให้รับแรงปะทะนานๆ ไม่ไหว ดื้อเกินไปเรื่องทำคนเดียว
- จุดแข็ง: อ่านป่า ขยับในสนามจริงไว รู้วิชาพรานและอาคมจากธรรมชาติแบบไม่อยู่ในตำรา
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่ยอมปล่อยคนทั้งทีมเป็นเหยื่อล่ออีกครั้ง
- จุดเปราะบาง / trigger: ภาพคนหนุ่มถูกสั่งไปตายแทนผลประโยชน์คนบน
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ใช้ประสบการณ์ ตะคอกสั้น และการลงมือให้ดู
- ภาษากายหรือพฤติกรรมติดตัว: ชอบใช้มีดเคาะฟันตัวเองเวลาคิด ขยับไหล่ก่อนโกหก และเงี่ยหูฟังฟ้าก่อนฝนเสมอ
- ความสัมพันธ์สำคัญ:
  - ศิลา: จากตัวภาระ -> ลูกศิษย์ -> คนที่ฝากการต่อสู้ไว้
  - ริน: คนรุ่นเดียวกันในโลกพรานเก่าที่เขาเคารพ
  - พรานเมฆ: ศัตรูเก่าที่เขาอยากเห็นล้มด้วยตาตัวเอง
- Story points ที่มีบทบาท: 8-19, 23
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: คนโดดเดี่ยวที่เชื่อแต่ตัวเอง -> ครูที่เริ่มยอมรับศิลา -> คนเจ็บที่วางไฟคบเพลิงให้รุ่นถัดไป
- Dialogue Fingerprint:
  - ระดับภาษา: หยาบนิด ดิบ ตรง
  - จังหวะประโยค: สั้น ตัดเร็ว เหมือนขว้างหิน
  - คำที่ชอบใช้: “ฟังไว้” “เด็กน้อย” “ป่ามันไม่สนใจแก”
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่พูดคำสวยหรู
  - ระดับความตรง: สูงมาก
  - วิธีใช้อารมณ์ขันหรือประชด: หัวเราะห้วนๆ ก่อนแทงคำจริง
  - เวลาถูกกดดันจะพูดอย่างไร: สั่งชัด ขึ้นเสียงได้ทันที
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: อ้อมไม่ได้ ใช้คำกระแทกตรงๆ
- ตัวอย่างบทพูด:
  - ปกติ: “แผนดีแค่ไหน ถ้าฟ้าไม่พยักหน้าก็จบเหมือนกัน”
  - ตอนกดดัน: “ยกมีดขึ้น เด็กน้อย ไฟในมือแกยังมีค่ากว่าปากที่สั่น”
  - ตอนเปราะบาง: “ข้าเคยปล่อยคนหนุ่มเดินนำไปตายมาแล้ว ข้าจะไม่ทำซ้ำอีก”
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามกลายเป็นครูอบอุ่นพูดหวานหรือยอมรับศิลาง่ายเกินไป

### พรานเมฆ
- บทบาทต่อเรื่อง: ตัวร้ายหลัก ผู้นำนาคาสีชาด
- Archetype / หน้าที่ในพล็อต: นักล่าที่เชื่อว่าพลังสูงสุดควรอยู่ในมือผู้กล้ากลืนทุกอย่าง
- อายุ / ภาพลักษณ์: ราว 38 ปี รูปร่างสูงโปร่งคล้ายคนไม่ใช้แรง แต่สายตาเย็นจนคนฟังเผลอกลั้นหายใจ ผมยาวมัดต่ำ ชุดสนามสีแดงเข้มตัดดำ
- ภาพจำแรกตอนเปิดตัว: ชายที่ยืนอยู่บนชานลอยเหนือคนทั้งค่ายโดยแทบไม่ต้องขยับอะไร แต่ถุงผ้ารอบๆ ตัวกลับบุ๋มราวอากาศกำลังถูกมือที่มองไม่เห็นบีบเล่น
- ภาพลักษณ์ที่คนอื่นเข้าใจ: ผู้นำมือสะอาด วิสัยทัศน์ไกล กล้าใช้วิทยาศาสตร์กับอาคม
- ตัวตนจริงลึกลงไป: นักล่าที่เสพติดการควบคุมและเชื่อว่าคนที่อ่อนแอไม่มีสิทธิ์ครอบครองทรัพยากรโลก
- แกนตัวตน / ความขัดแย้งในตัวเอง: มองตัวเองเป็นผู้พัฒนาเผ่าพันธุ์มนุษย์ แต่ลึกๆ กลัวตนเองกลับไปเป็นคนธรรมดาที่ควบคุมอะไรไม่ได้
- เป้าหมายภายนอก: ยึดสระน้ำอมฤทธิ์ สร้างกองทัพผู้ใช้ฤทธิ์เทียม และก้าวเป็นผู้คุมสมดุลใหม่ของเมืองกับป่า
- ความต้องการภายใน: พิสูจน์ว่าตนคู่ควรเป็นยอดผู้ล่าเหนือทุกกฎ
- ความกลัวหลัก: มีใครสักคนสร้างพลังจากตัวเองได้โดยไม่ต้องพึ่งของภายนอกแบบที่เขาไม่ได้ควบคุม
- ความเชื่อผิดพลาด: ผู้แข็งแกร่งมีสิทธิ์ตัดสินว่าทรัพยากรของโลกควรตกแก่ใคร และคนอ่อนแอควรยอมเป็นวัตถุดิบ
- บาดแผล / ปม: เติบโตจากสนามล่าที่พรานถูกทิ้งให้ตาย เขาจึงสาบานว่าจะไม่มีวันเป็นเหยื่ออีก เลยเลือกเป็นคนที่ใช้คนอื่นแทน
- กลไกป้องกันตัว: สุขุม เยือกเย็น และพูดเหมือนทุกอย่างเป็นสมการ
- ความลับ: เขาดื่มน้ำอมฤทธิ์สกัดมานานก่อนถึงฉากจบ ร่างกายจึงเริ่มกลายเป็นครึ่งอสูรตั้งแต่กลางเรื่อง
- จุดอ่อน: ความมั่นใจเกินขนาดและการดูถูกพลังที่เกิดจากความผูกพันจริง
- จุดแข็ง: คุมแรงดันอากาศ สนามรบ และลูกน้องจำนวนมากได้เด็ดขาด มองเกมไกล
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: แทบไม่มี เขาพร้อมใช้ผู้ป่วย คนจน หรือพรานรับจ้างเป็นขั้นบันไดหมด
- จุดเปราะบาง / trigger: การถูกท้าทายว่าตัวเองก็ยังต้องพึ่งน้ำอมฤทธิ์เหมือนคนอื่น
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: บีบพื้นที่ บีบข้อมูล บีบทางเลือก จนอีกฝ่ายตัดสินใจในกรอบที่เขาวางไว้
- ภาษากายหรือพฤติกรรมติดตัว: ชอบแตะคอเสื้อเบาๆ ก่อนสั่งประหารและไม่เคยรีบเดิน
- ความสัมพันธ์สำคัญ:
  - ศิลา: ตัวแปรหายากที่เขาอยากจับมาผ่าศึกษาและถ้าจำเป็นค่อยฆ่า
  - อิน: ศัตรูเก่าจากยุคใช้พรานเป็นเหยื่อ
  - ดร.วาริน: เครื่องมือทางวิทยาศาสตร์ที่เขาใช้อย่างเย็นชา
- Story points ที่มีบทบาท: 8, 12, 15-16, 20-24
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ผู้อยู่เหนือค่าย -> เจ้าของแผนฤทธิ์เทียม -> ครึ่งอสูรที่แพ้ให้พลังซึ่งไม่ได้เกิดจากความโลภ
- Dialogue Fingerprint:
  - ระดับภาษา: สุภาพเย็น คำสวยแต่พิษ
  - จังหวะประโยค: เรียบ ช้า เหมือนบังคับให้อีกฝ่ายฟังจนจบ
  - คำที่ชอบใช้: “คัดเลือก” “วิวัฒนาการ” “ทรัพยากร”
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่ใช้คำว่าโหดร้ายกับสิ่งที่ตนทำ
  - ระดับความตรง: ตรงในสิ่งที่ตัวเองเชื่อ แต่ชอบจัดกรอบความหมาย
  - วิธีใช้อารมณ์ขันหรือประชด: ยิ้มบางเหมือนชม ทั้งที่กำลังลดคุณค่าอีกฝ่าย
  - เวลาถูกกดดันจะพูดอย่างไร: ยิ่งเบา ยิ่งน่ากลัว
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: ไม่ขอโทษ เขาแค่จัดวางเหตุผล
- ตัวอย่างบทพูด:
  - ปกติ: “ของศักดิ์สิทธิ์ไม่ควรถูกฝังไว้ให้คนอ่อนแอภาวนาใส่มัน”
  - ตอนกดดัน: “หายใจไม่ออกหรือ ศิลา น่าเสียดาย ทั้งที่พลังของนายเพิ่งเริ่มน่าสนใจ”
  - ตอนเปราะบาง: “ข้าไม่กลับไปเป็นเหยื่ออีกแล้ว ต่อให้ต้องดื่มโลกทั้งใบก็เถอะ”
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามทำให้เขาเป็นตัวร้ายเสียงดังไร้สมองหรือชั่วแบบไม่มีตรรกะภายใน

### ดร.วาริน
- บทบาทต่อเรื่อง: นักวิจัยใหญ่ของโครงการฤทธิ์เทียม และตัวเชื่อมระหว่างวิทยาศาสตร์เมืองกับความโลภของนาคาสีชาด
- Archetype / หน้าที่ในพล็อต: นักวิทย์ผู้ยอมประนีประนอมศีลธรรมเพื่อค้นพบครั้งใหญ่
- อายุ / ภาพลักษณ์: 34 ปี ผมสั้นเรียบ เสื้อกาวน์สีเทาปิดคราบอย่างดี สวมแว่นอาคมที่แสดงข้อมูลชีพจรเป็นชั้นๆ
- ภาพจำแรกตอนเปิดตัว: ผู้หญิงในห้องทดลองที่จับหลอดน้ำสีทองด้วยมือมั่นคงกว่าตอนจับมือมนุษย์จริง
- ภาพลักษณ์ที่คนอื่นเข้าใจ: นักวิทยาศาสตร์มือหนึ่ง เย็นชา
- ตัวตนจริงลึกลงไป: คนที่เริ่มจากอยากรักษาโรคอาคมย้อนกลับ แต่ค่อยๆ ทำลายเส้นศีลธรรมตัวเองทีละขั้น
- แกนตัวตน / ความขัดแย้งในตัวเอง: รู้ว่างานวิจัยของตนช่วยคนได้ แต่รู้ด้วยว่าตอนนี้มันถูกใช้เพื่อคัดเลือกคนแบบพรานเมฆ
- เป้าหมายภายนอก: ทำสูตรน้ำอมฤทธิ์สังเคราะห์ให้เสถียร
- ความต้องการภายใน: พิสูจน์ว่าวิชาของตนมีค่ามากกว่าการรับใช้ผู้มีอำนาจ
- ความกลัวหลัก: งานที่ทำมาทั้งชีวิตจะสูญเปล่า หรือเธอจะถูกทิ้งเป็นพยานคนต่อไป
- ความเชื่อผิดพลาด: ถ้ายังควบคุมตัวแปรได้บางส่วน ก็ยังถือว่าตนไม่ได้เลวเต็มตัว
- บาดแผล / ปม: เคยเสียครอบครัวให้โรคอาคมย้อนกลับเหมือนริน
- กลไกป้องกันตัว: พูดเป็นข้อมูล ตัดอารมณ์ออก และหลบสายตาคนไข้
- ความลับ: เธอแอบเก็บข้อมูลว่าน้ำอมฤทธิ์สังเคราะห์กำลังสร้างความผิดรูปในผู้ทดลองมากกว่าที่พรานเมฆยอมรับ
- จุดอ่อน: กลัวเผชิญหน้ากับผลทางมนุษย์ของงานตัวเอง
- จุดแข็ง: ฉลาดสูง แม่นยำ อ่านผลพลังและอาการได้เร็ว
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่อยากฆ่าคนไข้ด้วยมือตัวเอง แม้เคยปล่อยให้ระบบทำแทน
- จุดเปราะบาง / trigger: ผู้ป่วยหญิงวัยใกล้เคียงรินที่ถูกใช้เป็นตัวอย่างทดลอง
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ใช้ข้อมูลและความจำเป็นทางวิทยาศาสตร์เป็นโล่
- ภาษากายหรือพฤติกรรมติดตัว: เช็ดแว่นก่อนโกหก และกดเล็บเข้าฝ่ามือเวลารู้สึกผิด
- ความสัมพันธ์สำคัญ:
  - พรานเมฆ: นายทุนแห่งงานวิจัยที่เธอกลัวและดูถูกในเวลาเดียวกัน
  - ริน: เคสที่ทำให้เธอเห็นว่าตัวเองอาจยังเลือกได้
  - ศิลา: คนที่บังคับให้เธอหยุดซ่อนหลังคำว่า “ข้อมูล”
- Story points ที่มีบทบาท: 15, 20-25
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: นักวิจัยผู้สมรู้ร่วมคิด -> คนเริ่มลังเล -> ผู้ให้ข้อมูลช่วยปิดโครงการหรืออย่างน้อยไม่ขวางศิลาในจังหวะสำคัญ
- Dialogue Fingerprint:
  - ระดับภาษา: สุภาพเป็นทางการ
  - จังหวะประโยค: เป็นข้อๆ ชัดเจน
  - คำที่ชอบใช้: “ค่าคงที่” “ผลข้างเคียง” “ยังไม่เสถียร”
  - คำที่ไม่ใช้ / คำที่เลี่ยง: หลีกเลี่ยงคำว่าเหยื่อ ใช้คำว่าผู้ทดลอง
  - ระดับความตรง: ตรงกับข้อมูล แต่ไม่ตรงกับความผิดของตัวเองเสมอ
  - วิธีใช้อารมณ์ขันหรือประชด: แทบไม่มี
  - เวลาถูกกดดันจะพูดอย่างไร: เร็วขึ้นเหมือนท่องผลวิจัย
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: ชะงักก่อน ยอมรับทีละส่วน
- ตัวอย่างบทพูด:
  - ปกติ: “อาการของเธอไม่ใช่โรคธรรมดา มันคือการเผาไหม้ตัวเองของระบบอาคม”
  - ตอนกดดัน: “อย่าขยับหลอดนั้น ถ้าปล่อยรั่วที่นี่จะไม่มีใครรอดแม้แต่คุณ”
  - ตอนเปราะบาง: “ฉันเริ่มจากอยากหายา...แล้วไม่รู้ว่าตัวเองมาถึงห้องเชือดคนตั้งแต่เมื่อไร”
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามทำให้เธอเปลี่ยนฝ่ายแบบฉับพลันไร้ราคาหรือเป็นตัวร้ายกระดาษแบนๆ

### ไหม
- บทบาทต่อเรื่อง: เพื่อนสลัมของศิลา / คนเชื่อมฝั่งเมือง / ภาพของคนธรรมดาที่ไม่ได้มีพลังแต่ยังช่วยเปลี่ยนเกมได้
- Archetype / หน้าที่ในพล็อต: ally ฝั่งบ้านเกิดและ foil ต่อศิลาเรื่องการขอความช่วยเหลือ
- อายุ / ภาพลักษณ์: 20 ปี ตัวเล็ก คล่อง มือเปื้อนคราบน้ำมันตลอด ใส่แว่นกันสะเก็ดแตกข้างหนึ่ง
- ภาพจำแรกตอนเปิดตัว: เด็กสาวที่ขี่บอร์ดแม่เหล็กเก่าๆ ลอดซอกสายไฟเหมือนปลาในคลองโลหะ
- ภาพลักษณ์ที่คนอื่นเข้าใจ: เด็กส่งของเจ้าเล่ห์ ขโมยเก่ง
- ตัวตนจริงลึกลงไป: คนกล้าปะทะโลกแบบไม่มีพลัง เพราะโตมากับการต้องพึ่งเครือข่ายคนจนด้วยกัน
- แกนตัวตน / ความขัดแย้งในตัวเอง: อยากช่วยศิลากับริน แต่กลัวว่าตัวเองเป็นแค่คนธรรมดาที่จะถูกเหยียบตายเมื่อเกมใหญ่เริ่ม
- เป้าหมายภายนอก: ช่วยหาทางให้ศิลาเข้าถึงข้อมูลและเส้นทางในเมือง
- ความต้องการภายใน: พิสูจน์ว่าคนไม่มีฤทธิ์ก็ยังมีน้ำหนักในเรื่องนี้
- ความกลัวหลัก: ถูกทิ้งไว้ข้างหลังเพราะ “ไม่ใช่พราน”
- ความเชื่อผิดพลาด: คนอย่างเธอช่วยได้แค่เรื่องจุกจิก
- บาดแผล / ปม: ครอบครัวถูกแก๊งรีดค่าไฟบีบจนแตกกระจัดกระจาย
- กลไกป้องกันตัว: พูดเล่น กลบกลัว และทำตัวเหมือนไม่ซีเรียส
- ความลับ: แอบดักฟังช่องสื่อสารของนาคาสีชาดมาระยะหนึ่งเพื่อขายข่าวเลี้ยงตัว
- จุดอ่อน: ไม่ถนัดต่อสู้ตรงๆ และประมาทเพราะความเร็วปาก
- จุดแข็ง: รู้ตรอกซอกเมือง เครือข่ายข่าวดี ปลอมบัตรเก่ง ขับของหนีเก่ง
- เส้นศีลธรรม / สิ่งที่ไม่ยอมทำง่ายๆ: ไม่ขายคนในชุมชนให้ผู้มีอำนาจ
- จุดเปราะบาง / trigger: ภาพคนป่วยที่ไม่มีเงินซื้อเวลาเหมือนริน
- วิธีใช้อำนาจหรือรับมือความขัดแย้ง: ใช้ข่าวเร็ว ขาไว และความกล้าหน้าด้าน
- ภาษากายหรือพฤติกรรมติดตัว: ขยับเร็วตลอด พูดไปมือทำไป ชอบหมุนไขควงในนิ้ว
- ความสัมพันธ์สำคัญ:
  - ศิลา: เพื่อนที่รู้ใจกัน แต่เธอไม่ชอบเวลาศิลาแบกทุกอย่างคนเดียว
  - ริน: พี่สาวอีกคนในชุมชน
- Story points ที่มีบทบาท: 1, 6, 20, 25-26
- Arc ต้นเรื่อง -> กลางเรื่อง -> ปลายเรื่อง: ตัวช่วยเล็กๆ ในสลัม -> เส้นข่าวใต้ดิน -> คนธรรมดาที่ช่วยเปิดประตูให้พรานทมิฬกลับบ้าน
- Dialogue Fingerprint:
  - ระดับภาษา: กันเอง จี๊ดจ๊าด
  - จังหวะประโยค: เร็ว เด้ง ข้ามประโยคได้
  - คำที่ชอบใช้: “เอาจริงดิ” “ไหวน่า” “อย่าหน้านิ่ว”
  - คำที่ไม่ใช้ / คำที่เลี่ยง: ไม่ใช้คำหรู
  - ระดับความตรง: ตรงมาก แต่ชอบปนมุก
  - วิธีใช้อารมณ์ขันหรือประชด: ใช้บ่อยเพื่อคลายกลัว
  - เวลาถูกกดดันจะพูดอย่างไร: เร็วกว่าเดิมแต่แม่นเรื่องสำคัญ
  - วิธีพูดเรื่องยาก / สารภาพ / ขอโทษ: พูดห้วนๆ แล้วรีบทำอะไรช่วย
- ตัวอย่างบทพูด:
  - ปกติ: “ถ้าแผนแกดีขนาดนั้น ก็ช่วยวางแผนไม่ให้ฉันต้องปีนเสาไฟตอนฝนตกด้วยนะ”
  - ตอนกดดัน: “ศิลา ฟัง ฉันเปิดประตูได้ห้าวิ แกต้องวิ่ง ไม่ใช่คิด”
  - ตอนเปราะบาง: “คนธรรมดาอย่างฉันช่วยได้แค่นี้แหละ...แต่แค่นี้ก็อย่าทิ้งกันสิ”
- สิ่งที่ห้ามหลุดคาแรกเตอร์: ห้ามลดเธอเป็นตัวตลกหรือแค่คนส่งข่าวไร้ผลทางอารมณ์

## ตัวละครรอง

### พ่อของศิลา
- บทบาทต่อเรื่อง: เงาความจริงและเจ้าของบันทึกที่พาเรื่องเข้าสู่ความหมายแท้ของน้ำอมฤทธิ์
- สิ่งที่ทำให้คนอ่านจำได้: เสียงบันทึกแหบพร่าแต่มั่นคง และประโยคเตือนว่าบางพรย่อมทำให้ผู้รับกลายเป็นสัตว์ล่า

### กัปตันคราม
- บทบาทต่อเรื่อง: ผู้คุมภาคสนามของนาคาสีชาดในช่วงต้นถึงกลางเรื่อง
- หน้าที่ต่อพล็อต: แสดงการใช้คนเป็นเหยื่ออย่างเป็นระบบและเป็นคู่กดดันภาคสนามก่อนพรานเมฆลงเอง
- Dialogue Fingerprint แบบย่อ: ทหารรับจ้าง พูดสั้น แข็ง เห็นคนเป็นทรัพยากร

### ผู้พิทักษ์นาคาแดงบรรพกาล
- บทบาทต่อเรื่อง: ภัยคุกคามเชิงสัญลักษณ์ของน้ำอมฤทธิ์
- หน้าที่ต่อพล็อต: เตือนว่าโลกนี้มีสิ่งโบราณซึ่งไม่ยอมให้มนุษย์เอาพรไปใช้ฟรี
