# World Bible

- แกนโลก: ไทยไซเบอร์แฟนตาซีที่เทคโนโลยีอาศัยอาคมและทรัพยากรวิญญาณ แต่ใต้เมืองที่ดูศิวิไลซ์ยังมีสลัมขโมยไฟและเขตป่าดึกดำบรรพ์ซึ่งกฎเมืองใช้ไม่ได้

- กติกาหลัก:
  1. อาคม = การหยิบยืมพลังจากแหล่งภายนอก เช่น สายไฟ แบตเตอรี่ เสาอาคม เมฆพายุ หรือแหล่งพลังของสัตว์อสูร
  2. การใช้อาคมต่อเนื่องหรือเกินขีดจะเกิด “อาคมย้อนกลับ” ทำให้ร่างกายถูกเผา กลายเป็นผลึก หรือระบบประสาทเสื่อมตามชนิดพลัง
  3. ฤทธิ์ = ขั้นสูงกว่าอาคม ผู้ใช้สร้างพลังจากภายในตัวเองได้ แต่ต้องผ่านการแตกขีดจำกัดหรือการกระตุ้นผิดธรรมชาติ
  4. น้ำอมฤทธิ์แท้รักษาระดับเซลล์และกระตุ้นศักยภาพฤทธิ์ แต่ถ้าใช้ผิด ปริมาณเกิน หรือผ่านการสังเคราะห์อาจเร่งความวิปลาสและการกลายสภาพ
  5. ป่าดึกดำบรรพ์ล้านปีบิดสัญญาณและกระแสไฟจากเมือง จึงทำให้เทคโนโลยีสมัยใหม่เสื่อมประสิทธิภาพอย่างรวดเร็ว

- สถานที่สำคัญ:
  - มหานครศิวิไลซ์ (The Neolith City): เมืองตึกสูงบนฐานโบราณสถานไทย มีรถรางพลังวิญญาณ กำแพงอาคม และเขตสลัมที่คนจนต้องตัดไฟเถื่อนใช้เอง
  - สลัมสายเหนือ: บ้านของศิลาและริน ทางเดินโลหะเปียกน้ำ ควันน้ำมัน กลิ่นสายไฟไหม้ และผู้คนที่รู้จักกันผ่านหนี้ค่าไฟมากกว่าชื่อจริง
  - ค่ายคัดเลือกนาคาสีชาด: พื้นที่กึ่งทหารกึ่งบริษัท มีจอประกาศสีแดง คอกอาวุธ และลานฝึกที่คัดแยกคนเหมือนวัสดุ
  - ชายป่ากำแพงฟ้า: รอยต่อระหว่างเมืองกับป่า เสาอาคมสูงเหมือนประตูแดนมนุษย์ จุดที่อุปกรณ์เริ่มรวน
  - ป่าดึกดำบรรพ์ล้านปี (The Primordial Wild): เขตพฤกษายักษ์ บึงมรณะ หน้าผาเมฆ และรากโลกขนาดมหึมา สัตว์อสูรใหญ่ราวตึก
  - สระน้ำอมฤทธิ์ (The Amrita Fount): ใจกลางรากโลก น้ำสีทองไหลช้าเหมือนโลหะเหลวและส่องแสงจากพื้นดิน ไม่ใช่สถานที่ศักดิ์สิทธิ์สะอาด แต่เป็นพลังดิบที่ทำให้มนุษย์ต้องกลัว
  - ฐานนาคาสีชาดในเมือง: ตึกวิจัยพรางตัวเป็นศูนย์พลังงานเอกชน มีชั้นแล็บลึกและสนามป้องกันหลายชั้น

- ภาพจำแรกของสถานที่สำคัญ:
  - มหานครศิวิไลซ์: ป้ายโฮโลแกรมกระพริบเหนือยอดเจดีย์เก่าที่ถูกครอบด้วยกระจกและสายเคเบิล
  - สลัมสายเหนือ: สะพานเหล็กสนิมแดงกับหยดน้ำจากท่ออุ่นที่ตกใส่แอ่งน้ำเรืองไฟ
  - ป่าโบราณ: ต้นไม้สูงเสียจนยอดหายเข้าเมฆและรากโตเหมือนกำแพงเมืองที่ยังหายใจ
  - สระน้ำอมฤทธิ์: แสงทองใต้ความมืดเขียวของรากไม้ พร้อมกลิ่นโลหะหวานคล้ายเลือดสดเจือดอกไม้
  - ฐานงูแดง: ผนังกระจกสะอาดเกินจริงในตึกที่ซ่อนเสียงร้องไว้ข้างใต้

- วัตถุสำคัญและภาพจำแรก:
  - มีดชาร์จไฟของศิลา: ใบมีดสั้นสีหม่น มีลายวงจรวิ่งตามสัน เมื่อชาร์จเต็มจะส่งเสียงจี๊ดเบาๆ ในด้าม
  - เข็มทิศของพ่อ: กล่องโลหะเก่ามีหน้าปัดสั่นผิดจังหวะเหมือนชี้ไปยังพลังมากกว่าทิศ
  - แบตเตอรี่สำรองแบบพราน: กระบอกทรงยาวคาดเอว ใช้หล่อเลี้ยงอาคมสายฟ้าขั้นยืมในเมือง
  - น้ำอมฤทธิ์แท้: ของเหลวสีทองข้นเป็นเส้นเมื่อยกขึ้นจากภาชนะ และเรืองเหมือนไฟมีชีวิต
  - น้ำอมฤทธิ์สังเคราะห์: สีทองซีดกว่า มีฟองสั่นใต้ผิวและอุณหภูมิผิดธรรมชาติ

- ระบบอำนาจ / เวท / เทคโนโลยี:
  - เมืองใช้ “Spirit Grid” หรือโครงข่ายอาคมพลังวิญญาณเป็นโครงสร้างไฟฟ้าแทนพลังงานฟอสซิล
  - คนชั้นล่างเข้าถึงไฟผ่านตลาดมืดและเส้นสายมากกว่ากฎหมาย
  - อาวุธอาคมทั่วไปใช้หลักดึงพลังผ่านสื่อกลาง เช่น โลหะอักขระ แกนเก็บประจุ หรือเครื่องเร่งวงจร
  - พรานทมิฬคือกลุ่มคนที่ล่าอสูรหรือสำรวจพื้นที่อันตรายเพื่อแลกทรัพยากร อาจรับงานรัฐ เอกชน หรือผิดกฎหมาย
  - นาคาสีชาดเป็นสมาพันธ์ผิดกฎหมายที่เอาวิทยาศาสตร์สมัยใหม่มาผสมการล่าป่าแบบทหารรับจ้าง

- กลุ่มอิทธิพล:
  - นาคาสีชาด: กลุ่มตัวร้ายหลัก เชื่อในการวิวัฒนาการด้วยทางลัด
  - กลุ่มทุนพลังงานเมือง: ลูกค้าหลักของทรัพยากรจากป่า สนใจผลวิจัยฤทธิ์เทียมแม้ไม่ลงมือเอง
  - เครือข่ายชุมชนสลัม: คนตัวเล็กที่ช่วยเหลือกันผ่านข่าว ไฟ และการลักลอบ
  - พรานอิสระรุ่นเก่า: คนที่ยังเชื่อว่าป่ามีสมดุล ไม่ใช่เหมืองทรัพยากร

- วัฒนธรรมและวิถีชีวิต:
  - คนเมืองคุ้นกับการใช้เครื่องรางไฟฟ้าแทนอุปกรณ์ธรรมดา เช่น เตา ตะเกียง หรือบัตรผ่านประตู
  - สลัมมีวัฒนธรรม “ช่วยกันต่อสาย” ใครมีไฟมากแบ่งให้คนข้างห้องแลกข้าว ยา หรือข่าว
  - วงการพรานใช้ภาษากายและรอยแผลเป็นเป็นเครดิตมากกว่าบัตรประจำตัว

- เศรษฐกิจและทรัพยากร:
  - ไฟฟ้าอาคมคือชีวิตประจำวันและสินค้าควบคุม
  - ชิ้นส่วนจากสัตว์อสูรใช้ทำเกราะ อุปกรณ์เก็บประจุ และสารเร่งอาคม
  - น้ำอมฤทธิ์เป็นทรัพยากรระดับพลิกระบอบ เพราะเชื่อมทั้งการรักษา การทหาร และตลาดมืด

- ภัยคุกคามหลัก:
  - อาคมย้อนกลับ
  - สัตว์อสูรยักษ์ในป่า
  - การบิดของสนามพลังในป่าที่ทำให้อุปกรณ์ล้มเหลว
  - องค์กรมนุษย์ที่มองคนเป็นวัตถุดิบมากกว่าสัตว์อสูรเสียอีก

- ข้อจำกัดที่ส่งผลต่อพล็อต:
  1. ศิลาไม่อาจพกพลังจากเมืองไปใช้ได้ตลอด ทำให้การเติบโตต้องเกิดจริง
  2. น้ำอมฤทธิ์แท้มีจำกัด จึงช่วยทุกคนไม่ได้
  3. ฤทธิ์ไม่ใช่พลังที่ใช้ได้ฟรี ต้องแลกด้วยระบบประสาทและความเสียหายทางร่างกาย
  4. การเปิดโปงนาคาสีชาดกลางเมืองต้องชนกับผลประโยชน์หลายชั้น ไม่ใช่แค่ยิงบอสแล้วจบ

- จุดในเรื่องที่จะใช้ข้อมูลโลกเหล่านี้:
  - ตอน 1-4: เมือง สลัม Spirit Grid และชนชั้น
  - ตอน 5-17: กฎป่า อาคมจากธรรมชาติ สัตว์อสูร และข้อจำกัดของเทคโนโลยี
  - ตอน 18-24: น้ำอมฤทธิ์แท้ รากโลก และด้านมืดของการล่าทรัพยากร
  - ตอน 25-36: ฤทธิ์เทียม โครงสร้างอำนาจในเมือง และการใช้เทคโนโลยีล้อมอาคม
