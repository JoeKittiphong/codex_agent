# Style Sheet

- โทนภาษา: เข้ม ตรง มีแรงกดดันต่อเนื่อง แต่ยังเปิดพื้นที่ให้เห็นความอบอุ่นเล็กๆ ระหว่างศิลาและริน
- POV: บุคคลที่สามจำกัดมุมมองที่ศิลาเป็นหลัก
- Tense: อดีตกาล
- ระดับภาษา: ไทยร่วมสมัย อ่านง่าย แต่เลือกภาพเปรียบเทียบให้คมและมีลักษณะเฉพาะของโลกไฟฟ้า-ป่าโบราณ
- ความเร็วของจังหวะเรื่อง: ตอนเมืองต้นเรื่องเร็วและคม, ตอนป่ามีช่วงหายใจแทรกความพิศวง, ตอนท้ายกลับมารวดเร็วและดุดัน
- หลักการใช้บทพูด:
  - ทุกตอนต้องมีบทพูดตรงอย่างน้อย 3 ช่วง
  - ศิลาพูดเร็วและตัดอารมณ์
  - รินพูดนิ่ง คม และมีน้ำหนักแบบคนผ่านสนามจริง
  - อินพูดดิบและใช้คำให้เจ็บแต่จริง
  - พรานเมฆพูดช้า สุภาพ และกดดันผ่านความเย็น
- หลักการใช้ภาพ:
  - เมือง = นีออน สายไฟ สนิม น้ำรั่ว กระจกครอบของเก่า
  - ป่า = มหึมา เปียก ชื้น หนักแน่น และไม่สนใจความเป็นมนุษย์
  - ห้องทดลอง = สะอาดเกินจริงจนดูรุนแรงกว่าเลือด
- หลักการใช้เสียง:
  - ใช้เสียงหึ่งของหม้อแปลง เสียงฟ้าไหลในโลหะ เสียงใบไม้เสียดกันเหนือหัว และเสียงอากาศหายไปในฉากพรานเมฆ
- หลักการใช้กลิ่น:
  - เมืองมีกลิ่นโอโซน น้ำมัน ฝุ่นร้อน และสายไฟไหม้
  - ป่ามีกลิ่นดินเปียก มอส เหงื่อ เลือดสัตว์ และอากาศเก่า
  - น้ำอมฤทธิ์มีกลิ่นโลหะหวานผิดธรรมชาติ
- หลักการใช้รส:
  - ใช้รสโลหะบนลิ้นเมื่อศิลาเครียดหรือใช้ไฟเกินขีด
  - ใช้รสขมของยาและน้ำฝนในสลัมเพื่อย้ำชีวิตชนชั้นล่าง
- หลักการใช้สัมผัส:
  - ผิวไหม้ไฟ ชื้นฝน ร้อนจากผลึกแก้วดำ และแรงกดอากาศของพรานเมฆต้องจับต้องได้
- หลักการเปิดตัวตัวละครครั้งแรก:
  - ให้เห็นพฤติกรรมกับร่างกายก่อนข้อมูล เช่น ศิลาตัดสายไฟด้วยมือสั่น, รินซ่อนอาการเจ็บ, อินหัวเราะใส่คำสั่ง, พรานเมฆทำให้อากาศรอบตัวบุ๋ม
- หลักการเปิดตัวสถานที่ครั้งแรก:
  - ใช้ sensory detail อย่างน้อย 3 มิติ พร้อมผูกกับมุมมองศิลา เช่น สิ่งที่เขากลัว สิ่งที่เขาคำนวณ หรือสิ่งที่เขาอยากหนี
- หลักการเปิดตัววัตถุสำคัญครั้งแรก:
  - วัตถุทุกชิ้นต้องมีหน้าที่ เช่น มีดชาร์จไฟ = ตัวแทนของการยืมพลัง, เข็มทิศพ่อ = ตะขอสู่อดีต, น้ำอมฤทธิ์ = ความหวังและหายนะพร้อมกัน
- สิ่งที่ควรหลีกเลี่ยง:
  - อธิบายระบบพลังทีเดียวหลายย่อหน้า
  - บทบรรยายเชิงวิเคราะห์ว่าฉาก “ทำหน้าที่อะไร”
  - คำเปรียบเทียบลอยๆ ซ้ำกันทุกตอน
  - ทำให้ป่ากลายเป็นแค่ฉากหลังสวยๆ แทนที่จะเป็นแรงต้านจริง
- ตัวอย่างประโยคอ้างอิง:
  - “ลวดทองแดงเย็นเฉียบในมือศิลา แต่เหงื่อที่ซึมตามฝ่ามือทำให้มันลื่นพอจะฆ่าคนได้ถ้าพลาดเพียงครั้งเดียว”
  - “ยอดไม้ข้างบนทับกันหนาจนท้องฟ้าดูเหมือนถูกโลกกลืนกลับลงไปแล้ว”
  - “ห้องทดลองขาวจัดจนเลือดบนพื้นดูเหมือนใครเอาสีไปหยดผิดโลก”
